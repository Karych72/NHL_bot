# Задача 59. Топ-5 моментов дня: исследование отбора через AI

**Блок:** продукт · **Надобность:** ⚪
**Область:** исследование (spike), продуктового кода нет; итог — рекомендация и карточка
задачи на реализацию.
**Источник:** просьба человека 2026-10-06 («раз в день собирать топ-5 игровых моментов;
брать, видимо, быстрым исследованием через AI»); реестр — [`../open_tasks.md`](../open_tasks.md).

## Кратко

Раз в день по подписке отправлять 5 лучших моментов прошедшей ночи с видео. В NHL API нет
оценки «красоты» момента, поэтому отбирать придётся самим. Задача — быстро выяснить, может ли
AI (LLM, при необходимости с разбором кадров видео) выбирать топ-5 заметно лучше простой
эвристики, и сколько это стоит.

## Что уже известно (разведка 2026-10-06, матчи 2026-10-05)

Проверено запросами:
- У каждого гола в `gamecenter/{id}/landing` → `summary.scoring[].goals[]` есть `highlightClip`
  (с повторами, ≈35 с, ≈9 МБ) и `discreteClip` (только гол, ≈9 с, ≈2,5 МБ). Это id Brightcove;
  в mp4 их превращает уже существующий `telegram_bot/video_replay.py`. Клип появляется через
  10–20 минут после гола, к утру есть все.
- Готового рейтинга нет: у Brightcove и `forge-dapi.d3.nhle.com` нет просмотров и лайков. Подборки
  NHL (`tags.slug=top-plays`) только недельные.
- Признаки для оценки, которые отдаёт API:
  - `shotType` (wrist/snap/backhand/tip-in/wrap-around; редкие — between-legs, cradle, bat);
  - `strength` (ev/pp/sh) и `goalModifier` (`empty-net` из топа исключать);
  - координаты броска;
  - время, период и счёт — из них видны овертайм и решающий гол в концовке;
  - `summary.threeStars` (три звезды матча);
  - скорость броска из NHL EDGE, но есть не у каждого гола.
- Трекинг шайбы (`pptReplayUrl`, `wsr.nhle.com`) без браузерных заголовков отвечает 403.
  Эндпоинт недокументированный, опираться на него рискованно.
- Внешние сигналы популярности: просмотры на YouTube-канале NHL (бесплатный ключ, но цифры
  набираются только через несколько часов); Reddit r/hockey (нужна авторизация OAuth). X — платный.

## Что исследовать

1. **База — эвристика.** Score из признаков выше. Сравнить её топ-5 за 3–5 ночей с недельными
   «Top plays» NHL как с ориентиром.
2. **LLM по признакам.** Передать модели список голов ночи с признаками (тип броска, ситуация,
   счёт, время, игроки) и попросить топ-5 с объяснением. Совпадает ли выбор с ориентиром лучше
   эвристики?
3. **LLM по кадрам.** Несколько кадров из `discreteClip` (ffmpeg уже в образе) отдать vision-модели.
   Различает ли она «красивый» гол от рядового и сколько это стоит за ночь (≈20–40 голов)?
4. Не только голы: есть ли в API клипы сейв-моментов и силовых, чтобы «моменты» не сводились к голам.

## Критерии приёмки

- Таблица: подход → совпадение с ориентиром на 3–5 ночах → стоимость за ночь → задержка → риски.
- Рекомендация: какой подход брать в реализацию. Зависимости (SDK LLM, ключи) — только с
  разрешения человека (Global Constraint 5).
- Заведена карточка задачи на реализацию подписки «Топ-5». Доставку она берёт у подписки с
  настраиваемым временем.
- Код исследования — одноразовый, в мастер не идёт.

## Подводные камни

- Ключ Brightcove мы вытаскиваем из их плеера, и NHL может его сменить. Тот же риск уже есть
  у видео-кнопок.
- Отправлять сами клипы NHL, а не ссылки на nhl.com, — юридически серая зона.
