# Задача 59. Топ-5 моментов дня: свой рейтинг из чужих подборок

**Блок:** продукт · **Надобность:** ⚪
**Область:** исследование (spike), продуктового кода нет; итог — рекомендация и карточка
задачи на реализацию.
**Источник:** просьба человека 2026-10-06 («раз в день собирать топ-5 игровых моментов»),
уточнение 2026-10-07: не оценивать моменты самим, а найти ресурсы, которые уже собирают такие
рейтинги, и на их основе сделать свой; реестр — [`../open_tasks.md`](../open_tasks.md).

## Кратко

Раз в день по подписке отправлять 5 лучших моментов прошедшей ночи с видео. В NHL API оценки
«красоты» момента нет, но её уже дают другие: редакционные подборки «лучшие моменты ночи»,
просмотры роликов, голоса сообщества. Задача — найти такие ресурсы, оценить, сколько их и
насколько их выбор расходится, и собрать из них свой топ-5: момент, который отметили несколько
источников, выше момента из одного.

## Что уже известно (разведка 2026-10-06, матчи 2026-10-05)

Проверено запросами:
- У каждого гола в `gamecenter/{id}/landing` → `summary.scoring[].goals[]` есть `highlightClip`
  (с повторами, ≈35 с, ≈9 МБ) и `discreteClip` (только гол, ≈9 с, ≈2,5 МБ). Это id Brightcove;
  в mp4 их превращает уже существующий `telegram_bot/video_replay.py`. Клип появляется через
  10–20 минут после гола, к утру есть все. Видео для отправки берём отсюда, из внешних
  источников — только выбор моментов.
- У Brightcove и `forge-dapi.d3.nhle.com` нет просмотров и лайков. Подборки NHL
  (`tags.slug=top-plays`) только недельные.
- Внешние сигналы популярности: просмотры на YouTube-канале NHL (бесплатный ключ, но цифры
  набираются только через несколько часов); Reddit r/hockey (нужна авторизация OAuth). X — платный.
- Признаки гола из API (`shotType`, `strength`, `goalModifier`, время/счёт, `threeStars`) годятся
  для запасного варианта и для разбивки ничьих между источниками.

## Что исследовать

1. **Какие ресурсы есть.** Найти, кто публикует рейтинг или подборку лучших моментов NHL за
   ночь или день. Кандидаты для проверки: NHL.com и YouTube-канал NHL (ролики «лучшие моменты
   ночи», просмотры по клипам голов), Reddit r/hockey (посты с клипами и их рейтинг), спортивные
   медиа (ESPN, Sportsnet, TSN, The Athletic, Bleacher Report / House of Highlights), каналы
   клубов. Список не исчерпывающий — найти и другие.
2. **Сколько их и как их забрать.** Для каждого ресурса: регулярность (каждую ночь или нет),
   во сколько появляется, формат (API, RSS, HTML, видео без текста), нужен ли ключ или платный
   доступ, можно ли сопоставить момент с голом в NHL API (игрок, матч, время). Ресурс, который
   нельзя забрать «легко» — без браузера, обхода защиты и платы, — отметить и отложить.
3. **Насколько они расходятся.** Собрать выборы 3–5 источников за 3–5 ночей и сравнить:
   пересечение топов, моменты только у одного источника, систематические перекосы (только
   голы, только свои клубы, только американские рынки).
4. **Свой рейтинг.** Предложить правило объединения: например, сумма очков по месту в каждом
   источнике с весом источника; ничьи и ночи без подборок закрывать признаками из API.
   Прогнать на тех же ночах и показать, что получилось.
5. Не только голы: если источники отмечают сейвы и силовые, есть ли для них клипы в NHL API.

## Критерии приёмки

- Таблица ресурсов: ресурс → регулярность → время появления → способ забрать (API/RSS/HTML) →
  ключ/цена → сопоставимость с NHL API → риски.
- Сравнение источников на 3–5 ночах: пересечения и расхождения топов.
- Правило своего рейтинга и его топ-5 на тех же ночах рядом с источниками.
- Рекомендация: какие источники брать в реализацию. Зависимости (SDK, ключи) — только с
  разрешения человека (Global Constraint 5).
- Заведена карточка задачи на реализацию подписки «Топ-5». Доставку она берёт у подписки с
  настраиваемым временем (Задача 60).
- Код исследования — одноразовый, в мастер не идёт.

## Подводные камни

- Подборки «за ночь» могут выходить позже утренней рассылки — время появления решает.
- Парсинг HTML чужих сайтов ломается от вёрстки и может нарушать их условия использования;
  API и RSS предпочтительнее.
- Ключ Brightcove мы вытаскиваем из их плеера, и NHL может его сменить. Тот же риск уже есть
  у видео-кнопок.
- Отправлять сами клипы NHL, а не ссылки на nhl.com, — юридически серая зона.
