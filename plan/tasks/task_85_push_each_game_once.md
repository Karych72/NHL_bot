# Задача 85. Рассылки без дублей: каждый матч ночи — подписчику ровно один раз

**Блок:** продукт · **Надобность:** 🟠
**Область:** `telegram_bot/push_digest_job.py` (`broadcast_if_due`, `run_morning_digest_broadcast`,
`run_team_scores_broadcast`, `run_country_broadcast`, `_send_country_game`),
`telegram_bot/subscription_repo.py` (`sent_games`, `mark_game_sent`, списки подписок),
`telegram_bot/stats_handlers.py` (`send_game_card_message`, `dispatch_day_digest_messages`),
тесты рассылок, `docs/telegram_bot.md` §7.
**Зависит от:** 87 (кэш `file_id` клипов) — рекомендуемый порядок, не жёсткий: обе правят
`push_digest_job.py`, и без 87 пришлось бы переписывать одноразовый `_ClipCache` дважды.
С Задачей 84 пересекается только текстом карточки. Оформление объединённого сообщения
в сдержанном rich-стиле — Задача 90, после этой.
**Источник:** разбор внешнего ТЗ «NHL Telegram Bot — редизайн сообщений, подписок и
уведомлений» (v1.0, 25.10.2026) и **правило человека 2026-10-25**, которое заменяет пункт ТЗ
«дайджест показывает все матчи, даже уже присланные» (§4.1, UC-07, AC-06).
Реестр — [`../open_tasks.md`](../open_tasks.md).

## Кратко

Правило человека 2026-10-25: в автоматических рассылках **каждый матч ночи приходит
подписчику ровно один раз** — независимо от того, через сколько подписок он в него попал
(страна RUS, страна BLR, команда, дайджест «Матчи»). Сообщение о матче одно и собирается
под набор подписок чата. Полный дайджест со всеми матчами — только по явной команде
(`/today`, меню `/stats` → дайджест); их не трогаем.

## Зачем и на что влияет

Сейчас (снимок 2026-10-25) один матч приходит подписчику до четырёх раз:
- по сообщению на каждую подписанную страну, игроки которой в нём играли
  (`run_country_broadcast` идёт по строке подписки × матч);
- карточкой по каждой подписанной команде — у подписчика обеих команд встречи дважды
  (`run_team_scores_broadcast` идёт по строке на команду);
- ещё раз в утреннем дайджесте (`run_morning_digest_broadcast` шлёт всю ночь).

Повторы топят то, ради чего подписка, и приучают пропускать сообщения бота.

## Степень важности

🟠: подтверждённый дефект продукта, который человек видит каждую ночь.

## Подробно

**Сейчас.** Три рассылки независимы. Страна — по матчу на каждом прогоне sync, когда матч в
`games` и у голов страны выложены клипы (к 11:00 МСК — с тем, что есть), отметка по паре
(подписка, матч) в `bot_game_sent`. Команда и дайджест — вместе, когда ночь загружена целиком
или в 11:00 МСК, отметка `last_sent_night` на строке подписки. Превью (Задача 78) тоже
пишет в `bot_game_sent`.

**Правило.** Единица учёта — пара (чат, матч). Матч, о котором чату уже ушло сообщение
итогов, другими рассылками итогов этому чату не шлётся.

**Решение человека 2026-10-27 — страны в одном сообщении.** Если в матче играли игроки
нескольких стран, на которые подписан чат (например, RUS и BLR), чату уходит **одно** сообщение
по матчу с блоками всех этих стран, а не по сообщению на страну. Клип гола, где участвовали
игроки двух стран, — один раз. Это не предложение, а требование: пункт 1 ниже уточняет только
вид сообщения.

**Предложение — подтвердить с человеком в начале задачи:**
1. **Одно сообщение о матче под подписки чата** (матч, где есть подписанная команда или
   игрок подписанной страны):
   - есть подписанная команда — полная карточка матча (как сейчас у команды), под ней блоки
     **всех** подписанных стран, чьи игроки играли (`send_game_card_message` уже дописывает
     блоки стран);
   - только страны — короткое сообщение (строка счёта + блоки всех подписанных стран одним
     сообщением — решение человека выше, кнопка «Карточка матча»), за ним голы этих стран альбомом — каждый клип
     один раз, даже если гол забил россиянин с ассистом белоруса;
   - время — по матчу, на первом прогоне sync после его конца, как страна сейчас.
2. **Дайджест «Матчи»** — только матчи ночи, о которых этому чату ещё ничего не ушло.
   Все матчи уже пришли по другим подпискам — дайджеста нет. Шапка, когда матчи
   отфильтрованы, — «Остальные матчи ночи» (формулировку согласовать). Время прежнее:
   ночь загружена или 11:00 МСК.
3. **Порядок прогона**: сначала сообщения по матчам, потом дайджест. Матч, чьё сообщение
   по подписке ещё ждёт (клипы не выложены), в дайджест не берётся — уйдёт своим
   сообщением; в 11:00 МСК сначала уходят все ожидающие, затем дайджест с остатком.
4. **Превью перед матчем** (Задача 78) — не дубль итогов: оно до игры. Учёт «ровно один
   раз» относится к итогам; превью считается отдельно, как сейчас.

**Когда матч готов к рассылке** — решение человека 2026-10-25: матч закончен и NHL выложила
клипы всех его голов (как у страны сейчас); **крайний срок — 11:00 МСК**, тогда матч уходит
с тем, что есть. Как клипы загружаются, хранятся и попадают в кнопки видео — Задача 87
(кэш `file_id`), здесь не решается.

**Решить с человеком в начале задачи** (кроме пунктов выше):
- Шапка «Матч вашей команды (дата)» — оставить или убрать.

**Хранение.** Отметка «итог матча ушёл в чат» — по паре (чат, матч). Вариант без миграции:
`bot_game_sent` по подписке + выборка «ушло ли чату» через `bot_subscriptions.chat_id` с
исключением `kind = upcoming_games` (иначе превью сочтётся итогом). Вариант с миграцией —
своя таблица (чат, матч). Выбрать в начале задачи; `last_sent_night` у `team_scores`
больше не пишется, у дайджеста остаётся (дайджест один на ночь).

**Подводные камни.**
- Ночь — по `night_of` (игровая дата NHL), не по календарной дате отправки в МСК.
- Подписка на страну добавлена посреди ночи: матчи, уже ушедшие в дайджесте, повторно не
  шлются — это и есть «ровно один раз».
- `Forbidden` (бот заблокирован) — деактивировать все подписки чата, а не одну строку.
- Сбой отправки сообщения матча: отметка ставится после попытки, как сейчас у страны, —
  матч не повторяется и в дайджест не попадает; это осознанная потеря, не дубль.
- Бюджет GC6: три рассылки сводятся в одну по матчу — следить, чтобы чистый прирост не
  превысил 300 строк, старые пути удалить (GC3).

**Критерии приёмки.**
- Тесты (на БД, где SQL): подписчик RUS + BLR + обеих команд матча получает о нём одно
  сообщение — карточку с блоками обеих стран; подписчик только RUS + BLR (без команд) на
  матч, где играли россиянин и белорус, получает одно короткое сообщение с двумя блоками
  стран, а не два; клип гола с участием игроков обеих стран — один раз; утренний дайджест
  этого матча не содержит; подписчик только «Матчи» получает дайджест всей ночи; все
  матчи ночи ушли по подпискам — дайджеста нет; превью не мешает отправке итогов;
  повторный прогон ничего не дублирует; `/today` по-прежнему показывает всю ночь.
- `docs/telegram_bot.md` §7 и шапка `push_digest_job.py` обновлены.
- Живая проверка на dev-боте: подписки на RUS, BLR, команду и «Матчи» — за ночь каждый
  матч приходит один раз; матч с россиянами и белорусами без подписанной команды — одним
  сообщением с обоими блоками.
- `make ci-local` зелёный.
