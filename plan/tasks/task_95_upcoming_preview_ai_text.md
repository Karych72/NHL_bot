# Задача 95. Превью перед матчем: ИИ-текст «на что смотреть»

**Блок:** продукт · **Надобность:** ⚪
**Область:** `telegram_bot/push_digest_job.py` (`run_upcoming_broadcast`), клиент и журнал ИИ
Задачи 81 (`telegram_bot/ai_router.py`, ключ `ANTHROPIC_API_KEY`), миграция (кэш текста на матч),
`docs/telegram_bot.md` §7.
**Зависит от:** Задачи 78 (подписка «Предстоящие матчи», часть A) и 81 (ключ, клиент, лог ИИ) —
обе закрыты 2026-10-28.
**Источник:** часть B Задачи 78 (просьба человека 2026-10-23), вынесена в отдельную задачу
2026-10-28 при закрытии 78; реестр — [`../open_tasks.md`](../open_tasks.md).

## Кратко

К превью подписки «Предстоящие матчи» добавить 2–3 предложения «на что смотреть в матче»,
которые пишет ИИ строго по нашим данным: форма, серии, личные встречи, прогноз модели.

## Зачем и на что влияет

- Превью сейчас — таблица сравнения и строка модели; текст объясняет их одной фразой и делает
  сообщение живее.
- Первая рассылка, где ИИ пишет текст сам, а не выбирает экран (81).

## Степень важности

⚪: украшение рассылки, ничего не блокирует; **делать ли — решение человека**.

## Подробно

**Состояние на 2026-10-28.** Часть A 78 на проде: на каждом слоте с 15:30 МСК подписчику уходит
одно превью (`run_upcoming_broadcast`, отметка `bot_game_sent`). `anthropic` в зависимостях и
ключ на VM обоих стеков — с Задачи 81 (разрешение GC5 2026-10-25).

**Что делать.**
- Текст генерируется **один раз на матч**, а не на подписчика, хранится и вставляется всем.
  Оценка: ~15 матчей в день × один короткий вызов — центы в день.
- В промпт — только факты из БД, которые уже есть в превью (`matchup_season_preview`) и строка
  прогноза; модель не добавляет своих. Клиент и запись в журнал — те же, что у 81.
- Сбой или таймаут ИИ не задерживает превью: оно уходит без текста, сбой — в логе (осмысленная
  реакция, GC4).

**Решить в начале (человек):** делать ли; бесплатно для всех или только для платных
подписчиков ([`../premium_payments/`](../premium_payments/)).

**Критерии приёмки.**
- Тесты: текст на матч генерируется один раз при нескольких подписчиках; сбой ИИ — превью
  уходит без текста; в промпте только переданные факты.
- Тесты SQL кэша — на БД (`make all-tests`, миграция).
- Живая проверка на dev-боте: превью с текстом перед матчем, текст без выдуманных фактов.
- `make ci-local` зелёный.
