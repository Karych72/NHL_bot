# Задача 53. `/tonight`: повторное нажатие матча не плодит сообщения

**Блок:** продукт · **Надобность:** 🟡
**Область:** `telegram_bot/stats_handlers.py` (`callback_tonight_game`, `send_game_card_message`), `tests/`.
**Источник:** отзыв по UI бота, 2026-10-03 (`plan/bot_UI_problem.md`, `img_32`);
реестр — [`../open_tasks.md`](../open_tasks.md).

## Кратко

Кнопку матча в `/tonight` можно нажимать бесконечно — каждое нажатие шлёт новую копию
карточки или превью.

## Подробно

- Повторное нажатие отвечает коротким reply на уже отправленный ответ: тап по цитате
  прокручивает чат к нему. Прошлая такая ссылка удаляется — на матч одна ссылка.
- Превью и карточка — разные ответы (матч, сыгранный после превью, открывается карточкой).
- Ответ удалён из чата — шлётся заново. Память — `chat_data` процесса: после перезапуска бота
  первое нажатие снова шлёт ответ.

**Критерии приёмки.** Тесты: второе нажатие — reply на первую карточку, третье удаляет прошлую ссылку, удалённый ответ шлётся заново, превью ≠ карточка.
