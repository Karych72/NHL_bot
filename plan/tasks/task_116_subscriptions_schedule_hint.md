# Задача 116. `/subscriptions`: подсказка о своих расписаниях на главном экране

**Блок:** продукт · **Надобность:** 🟡
**Область:** `telegram_bot/bot.py` (`_subscriptions_main_screen`, `_DELIVERY_NOTE`), тест
главного экрана подписок, `docs/telegram_bot.md` §11.
**Зависит от:** Задач 107 (кнопка «⏰ Расписания» в `/subscriptions`) и 108 (создание текстом).
**Источник:** просьба человека 2026-11-02 по скриншоту `/subscriptions`; реестр —
[`../open_tasks.md`](../open_tasks.md).

## Кратко

На главном экране `/subscriptions` под списком подписок написать, что можно завести своё
расписание: любой экран бота в своё время, — с примером фразы. Сейчас об этом говорит только
подвал внутри «⏰ Расписания (0)», куда пользователь без расписаний не заходит.

## Зачем и на что влияет

- Расписания (107–108) создаются только текстом, отдельной кнопки «создать» нет. Узнать о них
  можно из `/help` или нажав «⏰ Расписания (0)» — на скриншоте человека счётчик 0, и с главного
  экрана не понятно, что это и как его наполнить.
- Главный экран `/subscriptions` — место, где пользователь настраивает «что бот присылает сам»;
  там и нужна подсказка.

## Степень важности

🟡: заметность готовой функции; ничего не блокирует.

## Подробно

**Текущее состояние (снимок 2026-11-02, `origin/develop` = `42933e5`).** `_subscriptions_main_screen`
(`bot.py`): заголовок «Ваши подписки», список, подвал `_DELIVERY_NOTE` («Итоги ночи приходят… /
Превью матчей дня — с 15:30 МСК…»), кнопки, среди них «⏰ Расписания (N)». Подсказка
`_SCHEDULE_HINT` («Создать — напишите боту, например: присылай лидеров по голам по пятницам в 10.»)
есть только на экране `sub:s` (`_subscriptions_schedules_screen`).

**Что делать.**
1. В подвал главного экрана добавить строку о своих расписаниях с примером, например:
   «⏰ Свои расписания — любой экран в нужное время: напишите боту «присылай лидеров по голам по
   пятницам в 10».» Пример фразы — тот же, что в `_SCHEDULE_HINT`, одной константой, без копии
   текста. Точную формулировку согласовать с человеком на dev-боте.
2. Показывать строку всегда или только пока расписаний 0 — решить в начале (рекомендация:
   только при 0, у кого расписания есть, тот о них знает). Лимит бесплатного (одно расписание)
   в подсказке не упоминать: об этом скажет отказ при сохранении (108).
3. `docs/telegram_bot.md` §11 «Список и удаление» — упомянуть подсказку.

**Критерии приёмки.**
- Тест главного экрана: при 0 расписаний подсказка в тексте (и, если выбран вариант «только
  при 0», — её нет при ≥ 1).
- Живая проверка на dev-боте: `/subscriptions` на телефоне, текст не ломает раскладку.
- `make ci-local` зелёный.

**Подводные камни.**
- Подвал уже в две строки; третья не должна делать экран длиннее списка подписок — держать
  одну короткую строку.
