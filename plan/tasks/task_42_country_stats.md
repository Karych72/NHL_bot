# Задача 42. Статистика по странам

**Статус:** не начата · **Блок:** продукт · **Надобность:** ⚪
**Область:** `telegram_bot/bot_messages.py`, `script_bot.py`, `dialog_states.py`, `stats_handlers.py`, `bot.py`, `messages/*.txt`, статический справочник стран, `tests/`, `docs/architecture.md`.
**Порядок:** после релиза, окнами; порядок с 37, 38, 41 любой.
**Источник:** [`../stats/team_and_country_stats_plan.md`](../stats/team_and_country_stats_plan.md), Фазы E и F; реестр — [`../open_tasks.md`](../open_tasks.md), «Продуктовый бэклог».

## Кратко

`rosters.nationality` загружается за каждый сезон, но не используется нигде, кроме
whitelist в `database.py:62`. Задача — агрегаты по странам (число игроков, очки, голы),
экран «страна → топ игроков», отдельно вратари; опционально голы по странам среди забивших
(Фаза F). Правило учёта игрока без ростера на сезон — зафиксировать в коде; длинные
списки — пагинация по лимиту Telegram 4096.

## Зачем и на что влияет

- **Зачем.** Новая для пользователя ось статистики при уже загруженных данных: в сезоне
  2025/26 в ростерах 1061 запись и 18 стран (живая БД). Сейчас эти данные — мёртвый груз.
- **На что влияет.** Только бот и его тесты; появляется статический справочник кодов
  стран (эмодзи флага / русское название) — маленький dict в коде, без внешнего API
  в рантайме. Схема и пайплайн не меняются (Фаза F опирается на `all_goals ⋈ rosters`,
  сезон — через `games.season_id`).
- **Если не делать.** Ничего не ломается.

## Степень важности

⚪ **Можно не делать в этом цикле.** Продуктовый бэклог, независимый от релиза и трека B.

## Подробно

### Текущее состояние (сверено 2026-09-22)

- `rosters.nationality varchar(10)` — трёхбуквенные коды NHL API (CAN, USA, SWE, …);
  одна строка на `(player_id, season_id)`, `current_team_id` nullable.
- Единственное использование — whitelist колонок в `database.py`. В `bot_messages.py`
  нет ни одной функции по странам.
- Паттерны: пагинация лидербордов (`player_stat_leaderboard_page`,
  `stat_leaderboard_for_kind`, `bot_messages.py:953-1016`, кнопки prev/next), «Нет данных
  в этом диапазоне.» как текст пустой страницы, `truncate_telegram_text`.

### Что нужно сделать

**Фаза E — игроки**

1. **Справочник** код → флаг/название: статический dict рядом с шаблонами; неизвестный
   код показывать как есть, не падать.
2. **Топ стран:** `players_season_stats p ⋈ rosters r` по `(player_id, season_id)` для
   `config.SEASON_ID`, полевые (`position <> 'G'`); метрики `COUNT(*)`, `SUM(points)`,
   `SUM(goals)`, очки на игрока; порог минимального числа игроков на страну (например,
   ≥ 3) — константа с комментарием. При 18 странах экран умещается в одно сообщение,
   пагинация нужна на детализации.
3. **Детализация «страна → топ игроков»:** callback `cntr:<код>`, топ по очкам с порогом
   `games ≥ N` как у существующих лидербордов, пагинация по образцу `/leaders`. Код
   страны в SQL — только параметром `%s` и только из набора, полученного запросом топа.
4. **Вратари** — отдельный запрос к `goalies_season_stats ⋈ rosters` (победы, save%, GAA)
   в том же экране страны или подменю.
5. **Правило учёта:** игрок без строки `rosters` на сезон исключается (или попадает
   в «Unknown») — выбрать одно, записать в docstring и подписи экрана.

**Фаза F — голы по странам (опционально)**

6. `all_goals ⋈ rosters` по `goal_player_id` / `(player_id, season_id)`, сезон через
   `games.season_id` по `game_id`; подпись «забитые голы, не очки»; не смешивать
   с таблицей очков в одном экране.

**Общее**

7. Кнопки и состояния (`dialog_states.py`, `script_bot.py`), регистрация в `bot.py`;
   «Назад» на всех ветках.
8. Тесты формата по образцу интеграционных: топ стран, страница страны, вратари,
   невалидный `cntr:` callback, пустой сезон.
9. `docs/architecture.md`, план `stats/` — отметить фазы; `/help` — упомянуть раздел.
10. E и F — раздельные ветки, если дифф превысит 300 строк.

### Критерии приёмки (из реестра)

- Агрегаты по странам (число игроков, очки, голы) и топ игроков выбранной страны.
- Правило учёта игрока без ростера на сезон зафиксировано в коде.
- Пагинация по лимиту Telegram в 4096 символов.

### Проверка

- `make ci-local`; живой бот: топ стран, вход в страну с большим ростером (CAN)
  и с маленьким (порог), вратари; «Назад».

### Подводные камни

- Двойное гражданство в данных NHL не отражено — одна `nationality`; сказать об
  источнике в подписи, не изобретать.
- Игрок, сменивший команду внутри сезона, в `rosters` один раз на сезон — для стран
  не проблема, для профиля команды (41) — учитывать.
- Пустой сезон (Задача 36): экраны отвечают текстом, не пустой таблицей.
