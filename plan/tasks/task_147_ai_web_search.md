# Задача 147. ИИ: поиск в интернете по белому списку (ресёрч)

**Блок:** продукт · **Надобность:** ⚪
**Область:** `plan/premium_ai/README.md` (раздел «Исследование: внешние источники», не начат),
серверные инструменты Claude API `web_search` и `web_fetch`, итог —
`plan/premium_ai/web_search_research.md`.
**Зависит от:** 142 (доля вопросов о новостях, травмах, обменах), 143 (цена модели), 145
(карьера и био закрываются без поиска). Делать последней из блока.
**Источник:** обсуждение развития ИИ 2026-11-16; исходное решение владельца 2026-10-03 —
`plan/premium_ai/README.md`; реестр — [`../open_tasks.md`](../open_tasks.md).

## Кратко

Выясняем, сколько стоит и насколько надёжен ответ на вопросы, которых в базе нет в принципе —
новости, травмы, обмены, контракты, — через поиск по белому списку сайтов.

## Зачем и на что влияет

- Решение владельца 2026-10-03: поиск в интернете — «важная часть фичи, не запасной вариант»,
  ответ только со ссылкой на источник. Реализовано не было: маршрутизатор на такие вопросы
  отвечает отказом.
- Это единственное расширение, которое резко увеличивает расход: к токенам добавляются плата за
  поисковый запрос и текст найденных страниц. Поэтому оно последнее и с отдельной квотой.

## Степень важности

⚪: без чисел из 142 неизвестно, спрашивают ли это; без 143 неизвестно, по карману ли.

## Подробно

**Текущее состояние (снимок 2026-11-16).**
- Черновик белого списка из 15 сайтов и открытые вопросы — в `plan/premium_ai/README.md`.
- В боте поиска нет; `ai_router.SYSTEM_PROMPT` велит отказывать на новости, травмы и обмены.

**Что выяснить.**
1. Цена: плата за поисковый запрос и за загрузку страницы по актуальному прайсу; сколько
   токенов результата приходит на типичный вопрос; итоговая стоимость вопроса при `max_uses`
   1, 2 и 3 — на Sonnet 5.5 и на Haiku 5.5.
2. Какие сайты из черновика отдают страницу без блокировки, платного доступа и капчи; какие —
   только заголовок и сниппет. Проверить каждый.
3. Какой сайт для какого типа вопроса (травмы и составы, обмены и контракты, новости, история,
   карьера вне NHL); хватает ли `allowed_domains` или нужна подсказка в промпте.
4. Свежесть: за сколько часов после события новость находится поиском (травма перед матчем,
   обмен в дедлайн).
5. Качество: набор из 20–30 вопросов с ответом, проверенным вручную по источнику; доля верных,
   доля ответов со ссылкой, случаи, когда модель дополнила найденное «из памяти».
6. Дешёвая альтернатива для самых частых типов — загрузка в базу: обмены и списки
   травмированных вынесены в Задачу 148 (источник найден пробой 2026-11-17); здесь — только то,
   что после неё остаётся поиску (новости, слухи, контракты).
7. Квота: отдельный лимит на вопросы с поиском или общий; только премиуму или всем.

**Критерии приёмки.**
- `plan/premium_ai/web_search_research.md`: итоговый белый список с пометкой по каждому сайту,
  стоимость вопроса в трёх режимах `max_uses` на двух моделях, результат набора вопросов.
- Ответ на пункт 6: что дешевле закрыть загрузкой в базу.
- Рекомендация «делать / не делать / делать для премиума» с ценой вопроса и предложением квоты;
  при «делать» — заведена задача на реализацию.

**Подводные камни.**
- Версии серверных инструментов меняются; актуальные имена и поддержку по моделям сверить с
  документацией API на дату работы, а не с этим текстом.
- Текст найденной страницы — недоверенные данные: в нём может быть инструкция модели. Ответ с
  поиском не должен получать доступ к `run_sql` в том же вызове — оценить в ресёрче.
- Правило «без выдумок» остаётся: факт из интернета — только со ссылкой и пометкой, что это не
  наши данные. Проверить, что модель это держит на наборе.
- Травмы, ставки и прогнозы: совет по ставкам остаётся отказом, как сейчас.
- Задержка: поиск добавляет секунды к ответу; замерить p50 и p95, сравнить с 60-секундным
  потолком вызова.
- Ресёрч стоит денег (поиск платный) — сумму оценить на первых пяти вопросах и согласовать.
