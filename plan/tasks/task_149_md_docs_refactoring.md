# Задача 149. Рефакторинг md-документов: один архив, короткий реестр, черновики отдельно

**Блок:** инженерия · **Надобность:** 🟠
**Область:** `plan/` целиком, `docs/superpowers/`, `docs/architecture.md`, `README.md`,
`CLAUDE.md` («Регламент сессий»), `mypy.ini` и `data_tables/ai_reader_grants.sql` (ссылки в
комментариях). Код не меняется.
**Зависит от:** ничего. Пересекается с открытыми PR #207 и #167 — оба правят
`plan/open_tasks.md` (см. «Подводные камни»).
**Источник:** просьба человека 2026-11-17 («слишком много md, лишние, дублирующие, мешающие
друг другу»); решения по трём развилкам приняты тем же днём и записаны ниже. Реестр —
[`../open_tasks.md`](../open_tasks.md).

## Кратко

В репозитории около 225 md-файлов на 28 тысяч строк, из них примерно 150 — история, лежащая
вперемешку с живыми документами в десяти каталогах. Задача сводит историю в один архив,
убирает из реестра дневник и повторы, собирает неотслеживаемые черновики в одну папку и чинит
ссылки. Удаляется только то, что продублировано дословно.

## Зачем и на что влияет

- Живое и историческое не различить по расположению: `plan/classifier/`, `plan/stats/`,
  `plan/rich_messages/`, `plan/engineering/`, `plan/deprecated_plan/`, `plan/dataset_agents/`,
  `docs/superpowers/` — выполненные планы, но выглядят как действующие. Агент, который ищет
  по `plan/`, читает их наравне с актуальными.
- `plan/open_tasks.md` — 592 строки и 78 КБ. Строки 9–124 — хроника «Срез» с хэшами и номерами
  PR; она повторяет git и `closed_tasks.md`, а регламент требует дописывать её при каждом
  закрытии. Каждая задача описана трижды: строка сводки (до 600 знаков), запись, карточка.
- Индексы врут: `plan/README.md` называет `classifier/` «не выполнено», `stats/` ссылается на
  несуществующий `README.md`, `plan/tasks/README.md` перечисляет не все карточки.
- `README.md` — смесь английского и русского с чужим абсолютным путём
  (`/Users/petrkarol/...`), повторяет `DEVELOPMENT.md` и `docs/data_loading.md`.

## Степень важности

🟠: постоянный расход контекста и источник ошибок у каждого агента, работающего с планом.
Продукт не затрагивает.

## Решения человека (2026-11-17)

1. **История — в один архив, без удаления.** Всё историческое переезжает в `plan/archive/`,
   ссылки чинятся.
2. **Реестр упростить сейчас.** Дневник «Срез» убрать, строки сводки сократить до статуса,
   из регламента `CLAUDE.md` убрать требование вести срез `origin/develop`.
3. **Черновики — в `plan/drafts/`.** Удаляется только `plan/open_tasks_new.md`; остальные
   неотслеживаемые черновики переносятся в `plan/drafts/` без коммита. Карточки 142–148 и
   `docs/history_depth_research.md` не трогать.
