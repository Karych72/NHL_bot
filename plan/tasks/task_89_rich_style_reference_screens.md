## Кратко

Довести по правилам Задачи 88 экраны, которые человек открывает сам: `/start`, `/help`, меню
`/stats`, `/team` и профиль клуба, `/standings`, `/leaders`, `/countries`, `/advanced`.

## Зачем и на что влияет

Это лицо бота: длинные тексты справки и профили клубов, где больше всего служебных строк
и легенд. Сейчас легенда `/help` и расшифровка метрик `/advanced` занимают экран целиком при
каждом открытии.

## Степень важности

🟡: качество вида.

## Подробно

- Заголовок экрана — одна строка по правилу 1, контекст (сезон, «данные на …») — подвал.
- `/help`: команды — список; «Обозначения» — `<details>`.
- `/start`: короткое приветствие + «Быстрый старт»; без перечня всех команд в теле — он в `/help`.
- Профиль клуба: «Сезон» — плотный блок; «Все игроки: /BOS_FULL» и легенда — подвал / `<details>`.
- `/standings`: разделы конференций и дивизионов — заголовком по правилу 1, «линия плей-офф» —
  как есть.
- `/advanced`: расшифровка метрик — `<details>`; «Сохранить» (`copy_message`) проверить заново.
- Эмодзи — ревизия по правилу 5.

**Подводные камни.** Меню `/stats` правит одно сообщение (rich → rich): изменение высоты экрана
при переходах не должно уводить кнопки с экрана телефона — проверить вживую.

**Критерии приёмки.**
- Тесты экранов обновлены структурно (заголовок, подвал, `<details>`), без сравнения
  целых HTML-строк.
- Живая проверка на dev-боте: каждый экран из перечня — скриншот с телефона; оценка человека.
- `make ci-local` зелёный.
