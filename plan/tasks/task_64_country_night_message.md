# Задача 64. Рассылка «Страна X»: игрок в две строки, статистика по позиции, подписи видео

**Блок:** продукт · **Надобность:** 🟡
**Область:** `telegram_bot/bot_messages.py` (`country_night_message`, `country_night_goals`),
`telegram_bot/push_digest_job.py` (`_send_goal_videos`), их тесты, `docs/telegram_bot.md` §7.
**Зависит от:** ничего. Задачи 61 и 63 смержены (PR #64, #66).
**Источник:** отзыв человека 2026-10-08 на живую рассылку «🇷🇺 Россия — ночь 2026-10-07»;
реестр — [`../open_tasks.md`](../open_tasks.md).

## Кратко

Сообщение подписки на страну читать неудобно: у каждого игрока одна строка, в которой
подряд идут имя, команда и сжатые цифры («Svechkov (COL) 1+1 · 2 бр. · +2 · 12:55»).
Переделать: у игрока две строки, сверху имя, снизу статистика, и чуть больше статистики
в зависимости от позиции. Второе: видео голов уходят альбомом, а Telegram показывает под
ним подпись только первого клипа, поэтому все голы альбома выглядят голами одного игрока.

## Зачем и на что влияет

- Одна длинная строка на игрока не выравнивается, и цифры разных игроков не сравнить на глаз.
- По одной строке не видно, как игрок отработал свою роль: защитника оценивают по блокам,
  центрального — по вбрасываниям.
- Подпись альбома вводит в заблуждение: на живой рассылке 2026-10-07 гол Подколзина был
  подписан как гол Свечкова.

## Подробно

**Формат сообщения** (решение человека 2026-10-08). Формат остаётся списком, без `<pre>` и
`<code>`. У игрока две строки, между игроками пустая строка:

```
🇷🇺 Россия — ночь 2026-10-07

Svechkov (COL)
1+1 · +2 · 2 бр. · 3 хита · 12:55

Malkin (PIT, ц)
0+0 · +0 · 1 бр. · 1 хит · вбр. 7/12 · 17:22

Mintyukov (ANA, защ)
0+0 · −1 · 2 бр. · 3 блока · 17:45

Vasilevskiy (TBL)
28/30 · 93.3% · 60:00
```

- Первая строка: фамилия (жирным), команда. Пометка позиции ставится только у центральных
  (`ц`) и защитников (`защ`).
- Вторая строка:
  - все полевые — голы+передачи, ±, броски, время;
  - нападающие (C, L, R) — плюс хиты;
  - центральные (C) — ещё вбрасывания «выигр./всего»;
  - защитники (D) — блоки вместо хитов;
  - вратари — сейвы/броски, %, время, как сейчас.
- Позиция берётся из `rosters.position`, цифры — из `game_player_stats` (`hits`, `blocked`,
  `face_off_wins`, `face_off_taken`). Склонение («1 хит / 3 хита / 5 хитов») сделать как в
  соседнем коде, если там есть помощник; если нет — короткая подпись без склонения
  («хиты 3»). Ради одной строки новый модуль не заводить.
- Порядок прежний: полевые по очкам, затем по голам; вратари после полевых.
- Фамилии остаются латиницей: русских написаний в БД нет.

**Подписи видео.** Решить в начале задачи, спросив человека (на 2026-10-08 ответа нет):
- (а) каждый клип отдельным `send_video` со своей подписью — «Svechkov (COL) — WPG,
  2-й период 12:34»; сообщений в чате становится больше;
- (б) оставить альбом, а под ним дать один нумерованный список голов в порядке клипов.
Варианты (а) и (б) вместе не делать (Global Constraint 3).

**Вне задачи:** Никита Клепов (ANA, id 8486052) в рассылку RUS не попал. Код здесь ни при чём:
страна в `rosters.nationality` берётся из `birthCountry` в `/v1/roster`, а у Клепова там `USA`
(родился во Флориде), другой страны NHL API для него не отдаёт. Ручной список «считать
страной X» — отдельное решение человека, оно рядом с Задачей 62.

- Подписи видео по выбранному варианту, тест на параметры отправки.

- Живая проверка: рассылка за ночь, где играли российские нападающие, центральные,
