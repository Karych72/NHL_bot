# Задача 51. Сводка дня без моноширинного выравнивания

**Блок:** продукт · **Надобность:** 🟡
**Область:** `telegram_bot/bot_messages.py` (`day_digest_summary_body`, `digest_shown_match_count`), `telegram_bot/stats_handlers.py` (`dispatch_day_digest_messages`), `tests/`.
**Источник:** отзыв по UI бота, 2026-10-03 (`plan/bot_UI_problem.md`, `img_29`, `img_30`);
реестр — [`../open_tasks.md`](../open_tasks.md).

## Кратко

Строка матча сводки `/today` выровнена по счёту моноширинным `<code>` — на телефоне
хозяева «висят» по центру и выглядят криво; матчи идут сплошняком.

## Подробно

- Матч — «1. **Хозяева 3:2 Гости**» обычным шрифтом по левому краю.
- Счёт по периодам — следующей строкой с небольшим отступом (как было — «выглядит ок»).
- Между матчами — пустая строка (`DIGEST_GAME_SEPARATOR`); подсчёт обрезки под лимит Telegram
  учитывает тот же разделитель.

**Критерии приёмки.** Тесты: строка матча без `<code>`, периоды строкой ниже, пустая строка между матчами.
