# Задача 153. Бот только в личке: убрать ветки для групп

**Блок:** инженерия · **Надобность:** ⚪
**Область:** `telegram_bot/bot.py` (`/start`, `/premium`, `_PREMIUM_GROUP_TEXT`),
`telegram_bot/premium.py` (docstring), `tests/`, `docs/premium.md`, `docs/telegram_bot.md` §8,
`DEVELOPMENT.md` (ручная выдача группе).
**Зависит от:** ничего.
**Источник:** ответ человека 2026-11-17 («бот не может состоять в группах»,
[`../premium_open_questions.md`](../premium_open_questions.md), ответ 17); реестр —
[`../open_tasks.md`](../open_tasks.md).

## Кратко

Бот не может быть добавлен в группу, а код и документация описывают поведение в группах.
Эти ветки удаляются.

## Зачем и на что влияет

- Недостижимый код и текст в документации о «премиуме для группы» путают: непонятно, что
  поддерживается.
- На пользователей не влияет.

## Степень важности

⚪: мелкая чистка, можно делать попутно с любой задачей по `bot.py`.

## Подробно

**Текущее состояние (снимок 2026-11-17, `origin/develop` = `7f00d21`; строки сверять).**
- `bot.py:157` — пробник выдаётся только при `chat.type == "private"`.
- `bot.py:226` — `/premium` в группе отвечает `_PREMIUM_GROUP_TEXT`.
- `docs/premium.md` — «в группе `/premium` только объясняет…», «ручная выдача — единственный
  путь для группы».

**Что делать.**
1. Убедиться, что у обоих ботов (прод и dev) в BotFather выключено добавление в группы
   (Bot Settings → Allow Groups). Это делает человек.
2. Удалить ветки по типу чата и `_PREMIUM_GROUP_TEXT`, тесты на них.
3. Убрать упоминания групп из `docs/premium.md`, `docs/telegram_bot.md`, docstring.

**Критерии приёмки.**
- `grep -n "_PREMIUM_GROUP_TEXT" telegram_bot/ tests/` пуст.
- В документации нет поведения бота в группах; `make ci-local` зелёный.

**Подводные камни.**
- Бот пишет в канал (Задачи 118, 120). Канал — не группа: сообщения из канала приходят
  другим типом обновления, но фильтр `F.chat.type == "private"` у свободного текста
  (`bot.py:1321`) без проверки не снимать.
- Настройка BotFather — не код: если её включат обратно, бот в группе поведёт себя как в личке.

## Открытые вопросы человеку

1. Подтвердить настройку Allow Groups у обоих ботов.
