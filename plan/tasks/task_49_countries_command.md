# Задача 49. `/countries`: страны отдельной командой, игроки по амплуа

**Блок:** продукт · **Надобность:** 🟡
**Область:** `telegram_bot/bot_messages.py` (`country_rankings`, `country_page`),
`telegram_bot/stats_handlers.py`, `telegram_bot/bot.py`, `telegram_bot/script_bot.py`,
`telegram_bot/dialog_states.py`, `telegram_bot/help_text.py`, `tests/`.
**Источник:** отзыв по UI бота, 2026-10-03 (`plan/bot_UI_problem.md`, `img_23`);
реестр — [`../open_tasks.md`](../open_tasks.md).

## Кратко

Статистика по странам (Задача 42) спрятана на третьем уровне меню `/stats`, у страны
полевые игроки смешаны, строки не выровнены.

## Подробно

- Команда `/countries`: рейтинг стран — выровненная таблица, кнопки стран. Пункт
  «По странам» и состояние `COUNTRY_STATS` из `/stats` удаляются.
- Страна → нападающие / защитники / вратари (переключатель, листание). Колонки:
  нападающие — Г, О, ВП, Хит, Бр; защитники — то же с блоками; вратари — В, %ОБ, КН, И, Сух.
- Не влезающие в ширину телефона (36 символов) колонки убираются с наименее важной:
  силовые, затем броски/блоки, затем ВП; у вратарей — сухие, игры, КН. Броски/блоки
  уходят после силовых: они отличают экран нападающих от защитников.

**Критерии приёмки.** Тесты: рейтинг-таблица, группы F/D уходят в SQL условием на позицию,
ужатие колонок, код вне рейтинга, вратари, кнопки и `cn:list`.
