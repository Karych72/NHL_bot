## Кратко

Загрузить исторические закрывающие линии (исход с OT и тотал с ценами) за 2021-22 → сейчас,
де-вигнуть и сравнить модель с рынком на одних и тех же играх: log-loss модели против
log-loss закрытия, симуляция EV/ROI/CLV.

## Зачем и на что влияет

Без линий вопрос «обыгрываем ли мы букмекера» не измерить: любая метрика против константы
ничего не говорит о деньгах. Это эталон для 67, 68, 69, 71 и основа будущих сигналов в боте.

## Степень важности

🟠: не блокирует модель, но без неё цель трека недостижима.

## Подробно

### Решение человека (до начала)

- **The Odds API** — единственный найденный источник, явно разрешающий коммерческий показ
  производной аналитики (перепродажа данных запрещена). Исторические снимки с 2020-06-06,
  шаг 10 мин (с сентября 2022 — 5 мин). Снимок h2h + totals по ≤10 конторам — 20 кредитов.
  Закрытие нужно на каждый кластер стартов (≤30 мин), а не на игровой день: ~3440 снимков
  за пять сезонов ≈ 69K кредитов, плюс утреннее открытие ≈ 22K — **~91K ≈ один месяц
  тарифа 100K за $59**, подписку отменить после выгрузки ($30 / 20K хватает на ~1.5 сезона
  закрытия). Живые линии — бесплатный тариф (500 кредитов/мес, нужно ~250–300).
  Платный API — новая внешняя зависимость.
- SBRO бесплатно покрывает 2021-22, но другая контора и без коммерческого разрешения —
  в бенчмарк не смешивать, все сезоны из одного API. MoneyPuck, DailyFaceoff, OddsPortal
  коммерческого разрешения не дают.
- Какая контора — эталон (Pinnacle при наличии в выдаче за все сезоны, иначе консенсус).
  Pinnacle идёт с публичного сайта с возможной задержкой; дата его появления в истории не
  указана — проверить пробой.

### Что сделать

0. Проба до оплаты: 3–5 исторических запросов на бесплатном ключе (если история закрыта —
   в оплаченном месяце) на даты разных сезонов — наличие Pinnacle, число контор,
   линия тотала, точность `commence_time`.
1. Таблица `game_odds`: `game_id`, контора, рынок (h2h / totals), линия, цены, момент снимка
   (открытие / закрытие).
2. Бэкфилл 2021-22 → 2025-26 и текущего сезона: `markets=h2h,totals`, `bookmakers=` список
   ≤10 контор; закрытие — последний снимок перед первым стартом кластера, открытие —
   утренний снимок дня.
3. Де-виг нормировкой p_i = (1/O_i) / Σ(1/O_j); power/Shin — только как проверка устойчивости.
4. Отчёт: log-loss модели и закрытия по сезонам на тех же играх; симуляция ставок по правилу
   O_book > 1/p с порогом EV 2–3% по корзинам фаворит/андердог и больше/меньше; CLV.

### Критерии приёмки

- Разрыв log-loss модели с закрытием измерен по каждому сезону.
- Правило: ставки к деньгам допустимы, только если разрыв ≤ ~0.005 и CLV > 0 на ≥ 500 сигналах.
- `make all-tests` зелёный.

### Подводные камни

- Сопоставление игр API букмекера с `game_id` NHL — по дате и командам, с проверкой на дубли
  (перенесённые матчи). В `games` нет времени старта — брать `commence_time` или расписание NHL API.
- Ошибки в исторических снимках признаны документацией: отсеивать цены с неправдоподобной
  суммой 1/O и скачки.
- Тотал чаще 6.5, чем 5.5: сравнивать P(Over) на выставленной линии (умеет модель 67).
