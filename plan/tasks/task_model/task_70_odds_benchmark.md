# Задача 70. Линии букмекеров и рыночный бенчмарк

## Кратко

Загрузить исторические закрывающие линии (исход с OT и тотал с ценами) за 2021-22 → сейчас,
де-вигнуть и сравнить модель с рынком на одних и тех же играх: log-loss модели против
log-loss закрытия, симуляция EV/ROI/CLV.

## Зачем и на что влияет

Без линий вопрос «обыгрываем ли мы букмекера» не измерить: любая метрика против константы
ничего не говорит о деньгах. Это эталон для 67, 68, 69, 71 и основа сигналов в боте (73B).

## Степень важности

🟠: не блокирует модель, но без неё цель трека недостижима.

## Подробно

### Решение человека (до начала)

- **The Odds API** — единственный найденный источник, явно разрешающий коммерческий показ
  производной аналитики (перепродажа данных запрещена). Исторические снимки с 2020;
  разовая подкачка ~19K кредитов ≈ один месяц плана $30; живые линии — бесплатный тариф
  (500 кредитов/мес). Платный API — новая внешняя зависимость.
- SBRO бесплатно покрывает 2021-22 (и 2022-23 до 27 ноября); MoneyPuck, DailyFaceoff,
  OddsPortal коммерческого разрешения не дают.
- Какая контора — эталон (Pinnacle при наличии в выдаче, иначе консенсус).

### Что сделать

1. Таблица `game_odds`: `game_id`, контора, рынок (h2h / totals), линия, цены, момент снимка
   (открытие / закрытие).
2. Бэкфилл 2021-22 → 2025-26 и текущего сезона.
3. Де-виг нормировкой p_i = (1/O_i) / Σ(1/O_j); power/Shin — только как проверка устойчивости.
4. Отчёт: log-loss модели и закрытия по сезонам на тех же играх; симуляция ставок по правилу
   O_book > 1/p с порогом EV 2–3% по корзинам фаворит/андердог и больше/меньше; CLV.

### Критерии приёмки

- Разрыв log-loss модели с закрытием измерен по каждому сезону.
- Правило: ставки к деньгам допустимы, только если разрыв ≤ ~0.005 и CLV > 0 на ≥ 500 сигналах.
- `make all-tests` зелёный.

### Подводные камни

- Сопоставление игр API букмекера с `game_id` NHL — по дате и командам, с проверкой на дубли
  (перенесённые матчи).
- Тотал чаще 6.5, чем 5.5: сравнивать P(Over) на выставленной линии (умеет модель 67).
