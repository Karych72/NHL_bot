# The Odds API: что забираем, качество, стоимость

Исследование 2026-10-13/14 к Задаче 70 (карточка `task_70_odds_benchmark.md`, PR #81).
Уточняет раздел «The Odds API» в [`data_sources.md`](data_sources.md): прошлая оценка
(~19K кредитов ≈ $30) занижена примерно в 4 раза, если нужно закрытие по каждой игре.

## Что забираем

Эндпоинт: `GET /v4/historical/sports/icehockey_nhl/odds?date=…&markets=…&bookmakers=…` —
снимок всех ещё не начавшихся матчей на заданный момент, с `commence_time`, `last_update`
по конторе и рынку, `outcomes[].price` и `point`.

| Что | Брать | Комментарий |
|---|---|---|
| `h2h` — победа с учётом OT/буллитов | да | основной рынок, сравнение с моделью 68 |
| `totals` — основная линия + цены over/under | да | модель 67; только основная линия конторы (чаще 6.5) |
| `spreads` (пак-лайн ±1.5) | нет | модель его не предсказывает, только удорожает запрос |
| альтернативные тоталы, периоды | нет | в истории только с 2023-05-03 и только поштучно по событию (дорого) |
| контора | `bookmakers=pinnacle,draftkings,fanduel,…` | до 10 контор = 1 регион по цене; выгоднее, чем `regions=eu,us` |

Закрытие = последний снимок за несколько минут до `commence_time`. Снимки с 2020-06-06:
шаг 10 минут до сентября 2022, затем 5 минут.

## Стоимость

Цена снимка: 10 × рынки × регионы → h2h + totals, ≤10 контор = **20 кредитов**.
Пустой ответ бесплатен. Живые линии: рынки × регионы → **2 кредита**.

Прошлая оценка считала один снимок на игровой день (~950). Но старты разнесены во времени,
и ранний снимок даёт для вечерних игр линию, устаревшую на часы (часто до объявления
вратарей — самое значимое движение линии). Подсчёт по расписанию NHL API
(`api-web.nhle.com/v1/schedule`, регулярка + плей-офф):

| Сезон | Игр | Разных времён старта | Кластеров (старты в пределах 30 мин) | Игровых дней (UTC) |
|---|---|---|---|---|
| 2021-22 | 1401 | 869 | 702 | 234 |
| 2022-23 | 1400 | 852 | 657 | 223 |
| 2023-24 | 1400 | 852 | 691 | 230 |
| 2024-25 | 1398 | 866 | 709 | 222 |
| 2025-26 | 1394 | 828 | 679 | 215 |

- **Закрытие по кластерам:** ~3440 снимков × 20 ≈ **69K кредитов**.
- **Открытие** (утренний снимок, ~1120 дней × 20): ≈ **22K кредитов**.
- **Итого ~91K** — один месяц тарифа **100K / $59**, подписку отменить после выгрузки.
- Только закрытие — в $59 с запасом; в $30 (20K) влезает ~1.5 сезона.
- **Живые линии текущего сезона:** 3–4 кластера в день + утро ≈ 250–300 кредитов/мес —
  в бесплатные 500.

Тарифы (2026-10-13): Starter бесплатно 500/мес; 20K $30; 100K $59; 5M $119; 15M $249 — помесячно.

## Качество — что смущает

1. **Pinnacle** есть в регионе `eu` с пометкой «odds from public website which may incur
   a delay». С какой даты он в истории — не указано. Без него эталон — консенсус американских
   контор (маржа выше, линия менее «острая»).
2. **Гранулярность 5–10 минут** — «закрытие» это цена за 5–10 мин до старта (по кластеру —
   до 35 мин). Для бенчмарка достаточно, но это не идеальная закрывающая линия.
3. **Ошибки данных** — документация: «data errors aren't common but they can occur…
   they can still be present in historical odds snapshots». Нужен фильтр: сумма 1/O
   в правдоподобном диапазоне, отсев скачков.
4. **Сопоставление с `game_id`** — в `games` нет времени старта, только `day`. Сводить
   по дате + командам; время брать из `commence_time` или расписания NHL API; учесть
   перенесённые матчи.
5. **2021-22 из SBRO** бесплатно, но другая контора и без коммерческого разрешения —
   смешивать источники в одном бенчмарке плохо. Все пять сезонов из одного API —
   ~14K кредитов, уже в итоге выше.
6. **Лицензия:** коммерческий показ производной аналитики разрешён, перепродажа самих
   линий — нет.

## Проверка до оплаты

Расхождение: страница тарифов указывает историю и в Starter, документация — «only available
on paid usage plans». План:

1. Бесплатный ключ (регистрирует человек).
2. 3–5 пробных исторических запросов (по 20 кредитов из 500) на даты разных сезонов:
   есть ли Pinnacle, сколько контор, линия тотала 5.5/6.5, точность `commence_time`.
3. Если история на бесплатном закрыта — проба уже в оплаченном месяце $59.

## Решения человека

- Тариф: $59 разово (закрытие + открытие, 5 сезонов) или $30 и только закрытие за 1–2 сезона.
- Эталон: Pinnacle, если проба покажет его во всех сезонах, иначе консенсус.
