# Задача 66. Walk-forward по сезонам и Elo-baseline

**Блок:** трек B · **Надобность:** 🔴 (для трека B) · **Зависит от:** ничего
**Область:** `modeling/` (сплиты, отчёт, гейт), конфиги `modeling_*.yaml`, `docs/modeling_training.md`.
**Источник:** исследование 2026-10-09 ([`research/report_model_vs_bookmaker.md`](research/report_model_vs_bookmaker.md),
раздел «Holdout 2025-26 занижает качество»). Реестр — [`../../open_tasks.md`](../../open_tasks.md).

## Кратко

Перестроить оценку модели: вместо одного holdout (последние 15% дней 2025-26, 994 игры) —
rolling-origin по сезонам 2023-24, 2024-25, 2025-26 с прогревом 2021-22 (~3 900 игр). Гейт —
«побить Elo-baseline», а не константу.

## Зачем и на что влияет

- Сырой Elo проекта даёт log-loss 0.661–0.667 на 2022–25 и 0.690 на 2025-26: holdout Задачи 40 —
  кусок аномального сезона (хозяева 52.2% побед) с олимпийской паузой внутри. На нём ни одна
  модель не покажет значимого выигрыша, и сравнивать на нём модели бессмысленно.
- Все следующие задачи трека (67–70) принимаются по этой оценке.

## Степень важности

🔴 для трека B: без неё нельзя честно сказать, стала ли модель лучше.

## Подробно

### Что сделать

1. Сплит «тестовый сезон S → обучение и подбор гиперпараметров только на сезонах < S»;
   внутри S прогноз as-of (силы обновляются по дням, как в бою). 2021-22 — только прогрев.
2. Метрики по каждому сезону и на объединённой выборке: log-loss, Brier, ECE;
   block-bootstrap по дням для ДИ разности «модель − Elo» и «модель − константа».
3. Срезы в отчёте, а не выброс: первые 10% сезона, игры после олимпийской паузы
   (2026-02-05 … 2026-02-25 — паузы без игр).
4. Elo-baseline out-of-sample: параметры Elo подбираются только на прошлых сезонах
   (сейчас грид-поиск на 2022-10-01…2025-11-19 — частично in-sample).
5. Гейт `acceptance` сравнивает лучшую модель с Elo-baseline на объединённом walk-forward.
   Старый holdout-путь удалить (Global Constraint 3), а не держать рядом.

### Критерии приёмки

- Отчёт воспроизводим из `metadata`; Elo-baseline по сезонам опубликован в
  `docs/modeling_training.md`.
- Объединённая выборка ≥ 3 900 игр; ДИ разности заметно уже нынешних ±0.003–0.01.
- Текущие `home_win` lgbm/logreg прогнаны по новой схеме — их место относительно Elo известно.
- `make ci-local` зелёный.

### Подводные камни

- Сплит по сезонам меняет `metadata`/артефакты — проверить `predict` и `retrain` (Задача 26)
  на совместимость с новым форматом, а не оставлять старую ветку.
- Бюджет 300 строк (GC6): если отчёт по срезам раздувает дифф — вынести срезы во вторую подзадачу.
