## Цель трека

Бот даёт **честные вероятности** и справедливые коэффициенты (1/p) на победу хозяев (с OT/SO)
и на тотал (5.5 и любая выставленная линия), чтобы сравнивать их с линией букмекера.
Ставка имеет смысл только когда **кэф букмекера выше нашего справедливого** (EV = p·O − 1 > 0).

Обоснование выбора — исследование [`research/report_model_vs_bookmaker.md`](research/report_model_vs_bookmaker.md)
(2026-10-09, заметки — [`research/notes/`](research/notes/)). Главное оттуда:

- одна **голевая модель** (Poisson: λ хозяев и гостей → сетка счёта → OT/SO-слой) вместо двух
  бинарных классификаторов; тотал считается по правилу букмекеров (OT целиком, буллиты +1);
- 5–15 сильных признаков (силы команд, xG, вратари, отдых, дом) вместо 215 rolling-колонок;
- оценка — walk-forward по сезонам, эталон — Elo, затем де-виженная закрывающая линия;
- реалистичная цель — log-loss 0.655–0.665; устойчивого плюса против закрытия NHL публично
  не показал никто, поэтому деньги — только после сезона paper-сигналов с положительным CLV.
