# Задача 132. Один справочник команд бота вместо трёх списков

**Блок:** инженерия · **Надобность:** 🟡
**Область:** `telegram_bot/help_text.py` (`BOT_COMMANDS`), `telegram_bot/bot.py`
(`AI_COMMANDS`, регистрация `cmd_*`), `telegram_bot/ai_router.py` (`SCREEN_COMMANDS`,
`SCHEDULE_COMMANDS`), `tests/`.
**Зависит от:** ничего. Удобнее до Задачи 133 (разрезание `bot_messages.py`).
**Источник:** ревизия качества кода 2026-11-16, просьба человека завести задачи; реестр —
[`../closed_tasks.md`](../closed_tasks.md).

## Кратко

Команда-экран описывается в одном месте; меню Telegram, `/help`, список для ИИ-маршрутизатора
и расписания строятся из этого описания.

## Зачем и на что влияет

- Сейчас новая команда — это шесть правок: функция `show_*`, хендлер `cmd_*`, регистрация в
  роутере, `help_text.BOT_COMMANDS`, `bot.AI_COMMANDS` и `ai_router.SCREEN_COMMANDS`. Последние
  три списка синхронизируются вручную.
- Забытая правка в одном из списков даёт тихую ошибку: команда есть в меню, но ИИ её не
  откроет, или наоборот.

## Степень важности

🟡: удобство правки и защита от рассинхронизации.

## Подробно

**Текущее состояние (снимок 2026-11-16, `origin/develop` = `5a97128`).**
- `help_text.py:55` — `BOT_COMMANDS`: пары «команда, описание» для `/help` и
  `set_my_commands` (`bot.py:1194`).
- `ai_router.py:49` — `SCREEN_COMMANDS`: кортеж имён для `enum` инструмента `open_command`;
  `:58` — `SCHEDULE_COMMANDS`, производный от него.
- `bot.py:680` — `AI_COMMANDS`: имя → функция показа экрана; `:728` — словарь для расписаний.

**Что делать.**
1. Выбрать один справочник (по умолчанию — `AI_COMMANDS` в `bot.py`, дополненный описанием и
   признаками «открывается ИИ», «доступна в расписании», «есть в меню»).
2. `BOT_COMMANDS`, `SCREEN_COMMANDS`, `SCHEDULE_COMMANDS` и регистрацию хендлеров строить из
   него; ручные списки удалить.
3. Тест: набор команд в меню, в `enum` маршрутизатора и в расписаниях выводится из
   справочника; команда без функции показа — ошибка при импорте.

**Критерии приёмки.**
- Добавление пробной команды в справочник (в тесте) делает её видимой в `/help`, в `enum`
  `open_command` и в регистрации хендлера без других правок.
- Состав и порядок команд в меню Telegram и текст `/help` не изменились (живая проверка на
  dev-боте).
- `make ci-local` зелёный.

**Подводные камни.**
- Направление импорта: сейчас `ai_router` импортирует `help_text`, а `bot` — обоих. Справочник
  с функциями показа живёт в `bot.py`, и `ai_router` не может импортировать его без цикла.
  Данные без функций (имя, описание, признаки) держать в нижнем модуле, функции привязывать в
  `bot.py`.
- Порядок команд в меню сейчас задан порядком `BOT_COMMANDS` — сохранить.
- Задачи 114 и 124 правят тексты справки и собирают их из констант — сверить, если они уже в
  коде.
- Новый модуль не нужен (Global Constraint 2): справочник помещается в `help_text.py`.
