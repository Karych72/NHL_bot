# Задача 47. Лидерборды выровненной таблицей

**Блок:** продукт · **Надобность:** 🟡
**Область:** `telegram_bot/bot_messages.py` (`player_stats_with_count`, `team_stats_with_count`),
`telegram_bot/messages/`, `tests/`.
**Источник:** отзыв по UI бота, 2026-10-03 (`plan/bot_UI_problem.md`, `img_24`–`img_27`);
реестр — [`../closed_tasks.md`](../closed_tasks.md).

## Кратко

Строки лидербордов — свободный текст «1. Swayman [G] — 2 (BOS, игр: 2, сейвы: 54/57,
время: 122:25 (61:12/игра))»: колонки не выровнены, на телефоне строка переносится.
Время вратаря — лишнее, достаточно числа игр.

## Подробно

- Лидерборды игроков, вратарей и команд — таблица в `<pre>` с шапкой (`Игрок / Ком / Знач /
  И / Смен`, у вратарей `Сейвы` вместо смен и без позиции и времени, у команд — аббревиатура,
  игры, `В-П-ОТ`, очки). Строка — не шире 36 символов: фамилия обрезается до 10, а если
  всё равно шире (конец сезона, места от 10-го) — уходит хвост, затем игры.
- «В целом это касается любых статистик»: сводки по конференциям и дивизионам (подменю
  команд в `/stats`) — тоже выровненной таблицей с легендой; их шаблоны удаляются.
- Неиспользуемые в бою jinja-шаблоны лидербордов (`season_leaders_players.txt`,
  `team_stats.txt`), ветка `use_html=False` и `team_stats()` удаляются.

**Критерии приёмки.** Тесты на формат строк игроков, вратарей (без времени), команд,
NULL в хвосте → «—»; SQL вратарей не читает `time_on_ice`.
