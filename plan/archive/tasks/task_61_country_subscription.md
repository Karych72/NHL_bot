# Задача 61. Подписка «Страна X»: игроки страны за ночь и видео их голов

**Блок:** продукт · **Надобность:** 🟡
**Область:** новый `kind` в `bot_subscriptions`, рассылка в `telegram_bot/push_digest_job.py`,
видео через `telegram_bot/video_replay.py`, данные `rosters.nationality`, `all_goals`,
`game_player_stats`.
**Зависит от:** Задачи 60 — доставка в выбранное время; без неё можно отправлять вместе
с дайджестом.
**Источник:** просьба человека 2026-10-06 (пункты 2 и 3 — одной подпиской); реестр —
[`../closed_tasks.md`](../closed_tasks.md).

## Кратко

Подписчик выбирает страну (например, Россию). Утром он получает:
1. одно сообщение со статистикой всех игроков этой страны, сыгравших прошлой ночью
   (полевые — Г+П, бросков, ±, время на льду; вратари — сейвы, %);
2. альбомом — видео всех их голов. В одном альбоме Telegram (`sendMediaGroup`) помещается
   до 10 видео: голов больше — уходит вторым альбомом.

## Подробно

- Новая подсистема — до кода короткая спека (brainstorming → spec), Global Constraints 6:
  при >300 строк разбить на «статистика» и «видео».
- Национальность: `rosters.nationality` (из `birthCountry`). Разрыв: у ~360–410 игроков
  сезонов 2023–2026 она NULL (`next_steps_2026-10-01.md`). Нужен ли дозабор до старта, решить
  по доле NULL в текущем сезоне. Страна рождения ≠ сборная; в API статистики есть
  `nationalityCode` (`stats/rest/en/skater/bios`) — сверить, что нужно для «русских».
- Видео: `highlightClip` гола через `/v1/ppt-replay/{game}/{event}` → Brightcove → mp4 —
  уже есть в `video_replay.py`. Клипы ≈9 МБ / 35 с (с повторами) или ≈2,5 МБ / 9 с
  (`discreteClip`, только гол) — выбрать. Повторно использовать `file_id` после первой отправки,
  чтобы не грузить один гол много раз разным подписчикам.
- Ночь без игроков страны — не отправлять ничего (или одну строку — решить).
- Выбор страны — меню/команда, список стран как в `/countries` (Задача 42).
- Связь со статистикой по странам: Фаза F Задачи 42 («голы по стране») не делалась —
  проверить, не закрывается ли она здесь.

**Критерии приёмки.** На реальной ночи из БД: сообщение с игроками RUS совпадает с карточками
матчей; число видео = число голов RUS; >10 голов → два альбома. `make ci-local` зелёный.
