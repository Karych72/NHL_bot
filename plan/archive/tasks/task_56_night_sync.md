# Задача 56. Ночной sync каждые 30 минут

**Блок:** продукт · **Надобность:** 🟠
**Область:** `pipeline/scheduled_sync.py`, `pipeline/load_season_modern.py`, `tests/`, docs.
**Источник:** просьба человека 2026-10-05; реестр — [`../closed_tasks.md`](../closed_tasks.md).

## Кратко

Сервис `sync` (Задача 34) грузил данные раз в сутки в 08:00 UTC (11:00 МСК): матч, закончившийся
в 05:00 МСК, появлялся в боте только через 6 часов. Нужно — каждые 30 минут с 21:00 до 11:00 МСК,
чтобы завершённые матчи попадали в БД по ходу ночи.

## Подробно

- Слоты — `:00`/`:30` с 18:00 до 08:00 UTC включительно (29 прогонов за ночь). МСК без летнего
  времени, поэтому окно задано константами UTC.
- Дайджест подписчикам — только после слота 08:00 UTC; иначе он уходил бы каждые полчаса.
- Повторные прогоны одного окна дат не плодят строк: per-game таблицы — `DELETE` по `game_id`
  окна и `INSERT` в одной транзакции, сезонные — UPSERT, `scheduled_games` перезаписывается.
- «Матч закончен» — все три ответа gamecenter (`play-by-play`/`boxscore`/`landing`) в
  `gameState = OFF`. Stats REST (`gameStateId=7`) может опередить gamecenter: такая игра
  пропускается с предупреждением и подбирается следующим прогоном. `FINAL` (минуты после
  сирены до утверждения лигой) больше не замораживается в диск-кэше.
- Идущий матч в БД не пишется: счёт по ходу игры — Задачи 57–58, из NHL API в боте.

**Критерии приёмки.** Тесты на сетку слотов, слот дайджеста и пропуск не-`OFF` игры; двойной
прогон загрузчика на скретч-БД за одно окно — счётчики и содержимое таблиц не меняются.
