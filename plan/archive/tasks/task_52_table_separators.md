# Задача 52. Колонки таблиц через `|` и подпись показателя

**Блок:** продукт · **Надобность:** 🟡
**Область:** `telegram_bot/bot_messages.py` (`_aligned_columns`, `_pre_table`, `_pre_table_fit`, турнирная таблица, лидерборды), `telegram_bot/leaderboard_specs.py`, `tests/`.
**Источник:** отзыв по UI бота, 2026-10-03 (`plan/bot_UI_problem.md`, `img_31`);
реестр — [`../closed_tasks.md`](../closed_tasks.md).

## Кратко

В лидерборде соседние числа «Знач», «И», «Смен» сливаются; шапка «Знач» не говорит, что
это за показатель.

## Подробно

- Колонки всех `<pre>`-таблиц (лидерборды, страны, сводки конференций/дивизионов, профиль
  клуба, `/BOS_FULL`, турнирная таблица) разделены `|` — на месте пробела, ширина строки
  (≤ 36) не меняется. Список голов карточки и сравнение в превью матча — не таблицы, без `|`.
- Вместо «Знач» — подпись показателя (`STAT_COLUMN_LABELS`): «Очки», «Голы», «Пасы», «SAT%»,
  «%ОБ», «%бол»…

**Критерии приёмки.** Тесты: шапки и строки лидербордов с `|` и подписью; подписи есть у всех колонок `PLAYER_STAT_TITLES` и `TEAM_STAT_TITLES`.
