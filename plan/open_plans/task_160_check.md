# Задача 160 — что проверить человеку

Код, миграция 0032, промпт, бэкфилл и тесты — в ветке `task-160-goal-goalie`. Остаётся то, что требует БД.

1. Освежить `all_data/raw` на ноутбуке до последних сыгранных игр (скрипт сам упадёт, если кэш старее базы).
2. После мержа в `develop` и зелёного Release (миграция 0032 применилась на `nhl_dev`) — с ноутбука
   из корня чекаута: `sh scripts/backfill_goal_goalie.sh dev`. Скрипт печатает сверки: NULL без
   `empty_net` с 2021/22 = 0, расхождений с `shot_attempts` = 0, доля NULL по сезонам 3–7%.
   Для прода — `… prod` после релиза в `master`.
3. Пара вопросов в `scripts/ai_stats_eval.jsonl` («кому чаще всего забивал игрок X»): ожидаемые
   значения снять запросом после бэкфилла; затем `make ai-stats-eval`, `make all-tests`.
