### Задача 67. Голевая модель v1 🟨 🔴 (после 66)
Карточка — [`tasks/task_model/task_67_goal_model.md`](./tasks/task_model/task_67_goal_model.md).
Только голы, победа — Задача 68. Приёмка: тотал 5.5 — log-loss ниже константы с ДИ без 0 на
walk-forward (66); калибровка доли ничьих после 60 минут ±2 п.п. по сезонам; классификатор
`over_5_5` удалён. Явный `scipy` в `requirements-modeling.in` — разрешён человеком 2026-10-10.

**Статус: модель в репозитории, приёмка не пройдена** (2026-10-11, ветка `task-67-goal-model`, PR #86).
`modeling/goal_model.py` + `python -m modeling.cli evaluate-goals` (`docs/modeling_training.md` §2b):
Poisson GLM по голам основного времени, обучение один раз на всех прошлых сезонах, доля ничьих
отслеживается внутри сезона. Сумма трёх сезонов: тотал 5.5 −0.0008 к константе, ДИ
[−0.0026; +0.0010] — включает 0; ничьи в ±1 п.п. во всех сезонах. Разведка ~15 вариантов
(ежедневное переобучение, меньше/другие коэффициенты, EWMA голов и бросков, Elo, Platt) — все
около −0.001: силы команд тотал почти не двигают. По карточке задача не закрыта, `over_5_5`,
перевод `publish`/`retrain` не тронуты; по решению человека 🟨 до признаков, которые могут
сдвинуть тотал (вратари — 71, xG — 69): их проверять той же командой, затем снова приёмка 67.
xG проверен в Задаче 69 (2026-10-14, PR #88) — тотал не сдвинул, ДИ включает 0
(`docs/modeling_training.md` §2b); остаются вратари (71).
