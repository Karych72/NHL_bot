# ТЗ для ревьюера: Фаза 2 — инфраструктура проекта

**Роль:** независимый reviewer.  
**Источник:** `plan/engineering/refactoring_plan_2.md`, Фаза 2. Пара ТЗ: [`executor_tz.md`](executor_tz.md).

---

## 1. Принцип ревью

Оценивать **воспроизводимость**, **безопасность секретов** и **соответствие фактическим инструментам** репозитория (Makefile, pytest, линтеры).

---

## 2. Dockerfile / Compose

- [ ] Образ собирается без ручных недокументированных шагов.
- [ ] Нет утечки секретов в слои образа и `compose` (только env/bind mounts).
- [ ] Точка входа и рабочая директория корректны; зависимости ставятся из `requirements.txt` (или принятого lock-файла).
- [ ] Compose не описывает лишние порты/сервисы без обоснования.

---

## 3. GitHub Actions

- [ ] Workflow запускается на push/PR согласно принятой политике (или обоснованно иначе).
- [ ] **Линт, typecheck, тесты** реально выполняются и падают при ошибках (не «заглушки»).
- [ ] Версии Python и шаги установки согласованы с проектом.
- [ ] Нет жёсткой привязки к машине разработчика (пути, локальные кэши).

---

## 4. Документация

Проверить, что пользователю ясно, как повторить шаги локально (хотя бы ссылка на Makefile/README при наличии).

---

## 5. Вердикт

**approve / approve with nits / request changes** + список блокеров.
