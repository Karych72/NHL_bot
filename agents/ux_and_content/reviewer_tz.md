# ТЗ для ревьюера: Фаза 7 — UX и контент

**Роль:** независимый reviewer.  
**Источник:** `plan/engineering/refactoring_plan_2.md`, Фаза 7. Пара ТЗ: [`executor_tz.md`](executor_tz.md).

---

## 1. Принцип ревью

Приоритет: **отсутствие тупиков в UI**, корректность **callback/state machine**, **безопасность** подписок (**7.6**) и читаемость сообщений в Telegram.

---

## 2. Навигация (7.1, 7.2a–7.2d)

- [ ] После любого экрана статистики есть логичный `reply_markup` или явный выход. *(повторный срез: основные экраны /stats, `/leaders`, подтверждено; полный охват по плану — см. «Отложено» в `refactoring_plan_2.md`.)*
- [x] Переходы вратарей и `TEAM_STATS`/`CHOOSE_STATS` не смешивают сценарии команд/игроков.
- [x] Турнирная таблица доступна из меню и отображает ожидаемые данные.
- [x] «Назад» ведёт на **родительский** уровень, а не в случайный корень.
- [x] Выбор даты дайджеста покрывает три режима; edge cases (полночь, таймзона) задокументированы или обработаны. *(UTC/игровой день — текст в меню выбора даты.)*

---

## 3. Контент (7.3–7.5)

- [ ] Новые поля статистики соответствуют источнику данных (нет путаницы имён колонок). *(зависит от полного закрытия 7.3/7.4 в плане; выборочно не блокирует Фазу 7 по UX.)*
- [x] Таблицы не «ломают» layout в клиентах Telegram; HTML экранирован корректно. *(ключевые экраны на HTML + `html.escape`.)*
- [x] «Вычисляемые фичи» имеют понятное определение (что считается серией, какой сезон и т.д.). *(форма и хет-трик в карточке матча и `/help`.)*

---

## 4. Уведомления и команды (7.6–7.8)

- [x] Подписки не шлют спам; есть отписка; хранение предпочтений безопасно.
- [x] Новые slash-команды не конфликтуют с существующими; `/help` отражает актуальное меню.

---

## 5. Вердикт

**approve / approve with nits / request changes**. Блокеры: тупики в UI, неверные callback, XSS-риски в HTML, утечки данных в уведомлениях.

**Актуальный вердикт (повторный срез по коду):** **approve with nits**. Ниже — сверка с прежним `request changes` (раздел 6 архива); блокеры сняты, остаются второстепенные замечания по единому HTML и UX-шуму.
