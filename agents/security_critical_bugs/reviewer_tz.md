## 3. Технические проверки

1. Проследить цепочку: запрос к данным → именование колонок → форматирование в сообщении (нет перепутанных переменных).
2. Проверить регистрацию callback в `script_bot.py` и отсутствие дублирующих конфликтующих обработчиков.
3. Прогнать шаблон с фикстурой goal: отсутствие `KeyError`/пустого времени.
4. Если добавлены/изменены тесты — убедиться, что они проверяют **семантику**, а не только «строка не пустая».
