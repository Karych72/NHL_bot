## 1. Текущее состояние

### Используемые эндпоинты (9 штук)

| # | URL | Что собираем |
|---|-----|-------------|
| 1 | `api.nhle.com/stats/rest/en/team` | Справочник команд |
| 2 | `api-web.nhle.com/v1/standings/now` | Текущие standings (дивизион, конференция) |
| 3 | `api.nhle.com/stats/rest/en/team/summary` | Сезонная статистика команд |
| 4 | `api-web.nhle.com/v1/roster/{tri}/{season}` | Составы команд |
| 5 | `api.nhle.com/stats/rest/en/skater/summary` | Сезонная статистика полевых |
| 6 | `api.nhle.com/stats/rest/en/goalie/summary` | Сезонная статистика вратарей |
| 7 | `api.nhle.com/stats/rest/en/game` | Список завершённых матчей |
| 8 | `api-web.nhle.com/v1/gamecenter/{id}/play-by-play` | Голы, хиты, вбрасывания, удаления |
| 9 | `api-web.nhle.com/v1/gamecenter/{id}/boxscore` | Боксскор матча (игроки, вратари, броски) |

### Таблицы БД (10 штук)

`teams`, `teams_stats`, `rosters`, `players_season_stats`, `goalies_season_stats`, `games`, `all_goals`, `game_team_stats`, `game_player_stats`, `game_goalie_stats`

### Пробелы в текущих данных

Ряд полей в существующих таблицах заполняются нулями/заглушками:
- `players_season_stats`: все поля time_on_ice = `"00:00"` (summary-отчёт не возвращает TOI)
- `goalies_season_stats`: PP/SH/EV saves и shots = `0` (summary-отчёт не возвращает splits)
- `all_goals`: `empty_net`, `winner_goal`, `is_ppg`, `is_shg` = `False` (play-by-play не парсит эти детали, хотя данные доступны в `situationCode` и `goalModifier`)
- `game_team_stats`: `power_play_percentage/goals/opportunities` = `0.0` (не извлекаются из боксскора)
- `game_player_stats`: `power_play_assists`, `face_off_wins/taken`, `sh_goals/assists` = `0`

## 2. Stats API: расширенные отчёты

Базовый URL: `https://api.nhle.com/stats/rest/en`

Формат запроса одинаков для всех отчётов — `/{entity}/{report}?cayenneExp=seasonId=...&gameTypeId=2`. Поддерживает пагинацию (`start`, `limit`). Сейчас используется только отчёт `summary` для skater, goalie и team. Доступно значительно больше.

### 2.1 Отчёты по полевым игрокам (`/en/skater/{report}`)

| Отчёт | Что содержит | Интерес для бота |
|-------|-------------|-----------------|
| **`realtime`** | Missed shots, shots on goal, shots attempted, % бросков в створ. Giveaways, takeaways, hits, blocked shots (те же поля, что в summary, но точнее). | Средний — большинство метрик уже есть |
| **`faceoffpercentages`** | Процент вбрасываний по зонам (OZ, DZ, NZ), общий %. | Высокий — зональная разбивка вбрасываний уникальна |
| **`faceoffwins`** | Абсолютные числа: выигранных/проигранных вбрасываний по зонам. | Средний — дополняет faceoffpercentages |
| **`goalsForAgainst`** | Goals for/against в 5v5, PP, SH, EN. Также: SAT% (Corsi), USAT% (Fenwick). | **Высокий** — продвинутая аналитика: Corsi/Fenwick |
| **`penalties`** | Minor, major, misconduct, game misconduct, match, penalty minutes. Детализация по типам удалений. | Средний — интересно для "грязных игроков" |
| **`penaltykill`** | PK TOI, SH goals against, SH goals for во время PK. | Низкий — специфическая метрика |
| **`penaltyShots`** | Попытки буллитов, голы с буллитов, процент реализации. | Высокий — интересная, но редкая статистика |
| **`powerplay`** | PP TOI, PP goals, PP assists, PP points, PP shots. | Средний — частично есть в summary |
| **`puckPossessions`** | SAT% (Corsi), USAT% (Fenwick), time on ice, зональные старты (OZ%, DZ%, NZ%). | **Высокий** — Corsi/Fenwick + zone starts |
| **`summaryshooting`** | Shooting %, goals, satPct (shot attempts), missed shots, shots on net. | Средний — пересекается с summary |
| **`percentages`** | OZ start%, шутинг%, фейсоф%, Corsi% (5v5), PDO. | **Высокий** — PDO и Corsi% в одном месте |
| **`scoringRates`** | Goals/60, assists/60, points/60, primary points/60 (5v5 и all). | **Высокий** — нормированные показатели на 60 мин |
| **`scoringpergame`** | Очки за матч, голы за матч. | Низкий — легко вычислить из имеющихся данных |
| **`shootout`** | Буллиты: attempts, goals, %, game-deciding goals. | Высокий — буллитная статистика отдельно |
| **`shottype`** | Разбивка по типу броска: wrist, slap, snap, backhand, tip-in, deflection, wrap-around. Голы и броски по каждому типу. | **Высокий** — уникальные данные |
| **`timeonice`** | TOI total, per game, EV/PP/SH/OT TOI (total и per game). | Высокий — заполнит пустые `"00:00"` в текущей таблице |
| **`bios`** | Рост, вес, draft year/round/overall, birth city/province/state. | Средний — обогащение профиля игрока |

### 2.2 Отчёты по вратарям (`/en/goalie/{report}`)

| Отчёт | Что содержит | Интерес для бота |
|-------|-------------|-----------------|
| **`advanced`** | Goals saved above expected (GSAE), high-danger SV%, medium-danger SV%, low-danger SV%. | **Высокий** — GSAE = ключевая современная метрика вратарей |
| **`bios`** | Рост, вес, draft info, место рождения. | Средний |
| **`daysrest`** | Статистика в зависимости от дней отдыха (0, 1, 2, 3+). | Средний — интересный нишевый анализ |
| **`penaltyShots`** | Saves/goals against на буллитах. | Средний |
| **`savesByStrength`** | SV% и saves при EV, PP, SH отдельно. | Высокий — заполнит пустые `0` в goalies_season_stats |
| **`shootout`** | Процент отражения буллитов в шутаутах. | Средний |
| **`startedVsRelieved`** | Статистика стартовых матчей vs. выход на замену. | Средний — показывает надёжность как стартера |

### 2.3 Отчёты по командам (`/en/team/{report}`)

| Отчёт | Что содержит | Интерес для бота |
|-------|-------------|-----------------|
| **`leadingtrailing`** | Wins/losses при ведении в счёте после 1-го, 2-го периода, при проигрыше. | **Высокий** — "камбэчность" команды |
| **`scoretrailfirst`** | Процент побед при забитом первом голе vs. пропущенном. | **Высокий** — дополняет leadingtrailing |
| **`goalsbyperiod`** | Голы за 1-й, 2-й, 3-й, OT периоды. | Средний — частично есть в game_team_stats |
| **`goalsforbystrength`** | Голы за в EV, PP, SH. | Средний — частично есть |
| **`goalsagainstbystrength`** | Голы против в EV, PP, SH. | Средний |
| **`realtime`** | Missed shots, blocked shots, hits, giveaways, takeaways (командные). | Низкий — почти всё есть |
| **`shottype`** | Командная разбивка по типу броска. | Средний |
| **`shootout`** | Командная буллитная статистика. | Средний |
| **`daysbetweengames`** | Результаты в зависимости от отдыха (1, 2, 3+ дня). | Средний — нишевый, но интересный |
| **`outshootoutshotby`** | Рекорд при большем/меньшем количестве бросков. | Средний |
| **`penalties`** | Командные удаления по типу. | Низкий |
| **`penaltykill`** | PK%, PK goals against, times SH. | Низкий — есть в summary |
| **`penaltykilltime`** | Среднее время PK. | Низкий |
| **`powerplay`** | PP%, PP goals, PP opportunities. | Низкий — есть в summary |
| **`powerplaytime`** | Среднее время PP. | Низкий |
| **`faceoffpercentages`** | Командный % вбрасываний по зонам. | Средний |
| **`faceoffwins`** | Вбрасывания: wins/losses по зонам. | Средний |
| **`summaryshooting`** | Sat%, USat% (Corsi/Fenwick команды), shooting%. | Высокий — командный Corsi/Fenwick |
| **`percentages`** | PP%, PK%, шутинг%, SV%, PDO. | Средний — частично есть |
| **`goalgames`** | Рекорд: 0 голов, 1, 2, 3, 4, 5, 6+ голов. | Средний — забавная статистика |

## 3. NHL EDGE: аналитика трекинга

Базовый URL: `https://api-web.nhle.com/v1/edge/`

NHL EDGE — система трекинга игроков и шайбы через инфракрасные датчики (до 60 замеров/сек для шайбы, 15/сек для игроков). Данные доступны начиная с сезона 2022-2023. Абсолютно не используются в проекте.

### 3.1 Скорость катания игроков

| Эндпоинт | Описание |
|----------|----------|
| `/v1/edge/skater-speed-top-10/{pos}/{sort}/{season}/{type}` | Топ-10 самых быстрых игроков |
| `/v1/edge/skater-skating-speed-detail/{playerId}/{season}/{type}` | Детали скорости: макс. скорость, рывки 22+ mph, 20-22 mph, 18-20 mph |

**Доступные данные:** максимальная скорость катания, количество рывков (bursts) по скоростным категориям.

**Параметры:** позиция (F/D/all), сортировка (max, bursts22, bursts20).

**Ценность:** Высокая. Визуально впечатляющие данные — "самый быстрый игрок НХЛ". Хорошо для Telegram-сообщений.

### 3.2 Дистанция катания

| Эндпоинт | Описание |
|----------|----------|
| `/v1/edge/skater-distance-top-10/{pos}/{strength}/{sort}/{season}/{type}` | Топ-10 по дистанции |
| `/v1/edge/skater-skating-distance-detail/{playerId}/{season}/{type}` | Детали: тотал, per 60, per game, per period |

**Доступные данные:** общая дистанция за сезон, средняя дистанция за 60 минут, рекордная дистанция за матч/период. Фильтр по ситуации (EV/PP/PK/all).

**Ценность:** Средняя. Интересно, но менее "цепляющее" для аудитории, чем скорость.

### 3.3 Зональное время

| Эндпоинт | Описание |
|----------|----------|
| `/v1/edge/skater-zone-time-top-10/{pos}/{strength}/{sort}/{season}/{type}` | Топ-10 по зональному времени |
| `/v1/edge/skater-zone-time/{playerId}/{season}/{type}` | Детали: OZ/NZ/DZ time, zone starts |
| `/v1/edge/team-zone-time-top-10/{strength}/{sort}/{season}/{type}` | Командное зональное время |
| `/v1/edge/team-zone-time-details/{teamId}/{season}/{type}` | Детали зонального времени команды |

**Доступные данные:** время в зоне атаки, нейтральной, обороны. Зональные старты. По ситуации (EV/PP/PK).

**Ценность:** Высокая для продвинутых пользователей. Показывает стиль игры команды/игрока.

### 3.4 Скорость броска

| Эндпоинт | Описание |
|----------|----------|
| `/v1/edge/skater-shot-speed-top-10/{pos}/{sort}/{season}/{type}` | Топ-10 самых мощных бросков |
| `/v1/edge/skater-shot-speed-detail/{playerId}/{season}/{type}` | Детали: макс. скорость, средняя, 100+ mph, 90-100, 80-90, 70-80 |

**Доступные данные:** топ-10 самых мощных бросков игрока, средняя скорость, распределение по скоростным группам.

**Ценность:** Высокая. "Самый мощный бросок в НХЛ" — отличный контент для бота.

### 3.5 Локация бросков

| Эндпоинт | Описание |
|----------|----------|
| `/v1/edge/skater-shot-location-top-10/{pos}/{cat}/{sort}/{season}/{type}` | Топ-10 по зонам бросков |
| `/v1/edge/skater-shot-location-detail/{playerId}/{season}/{type}` | Детали: high-danger/mid-range/long-range |

**Доступные данные:** броски, голы и % реализации из зон high-danger, mid-range, long-range.

**Ценность:** Средняя. Данные интересные, но требуют визуализации для понимания.

### 3.6 Командные EDGE-метрики

Аналогичные эндпоинты для команд:
- `/v1/edge/team-skating-speed-*` — скорость катания команды
- `/v1/edge/team-skating-distance-*` — дистанция команды
- `/v1/edge/team-shot-speed-*` — скорость бросков команды
- `/v1/edge/team-shot-location-*` — локация бросков команды
- `/v1/edge/team-comparison/{teamId}/...` — сравнение со средним по лиге (включая карту бросков!)
- `/v1/edge/team-detail/{teamId}/...` — рейтинг команды по всем EDGE-показателям

**Ценность:** Высокая. `/team-comparison` даёт данные для сравнения со средним по лиге.

### 3.7 Вратарские EDGE-метрики

| Эндпоинт | Описание |
|----------|----------|
| `/v1/edge/goalie-detail/{playerId}/...` | GAA, games above .900, goal diff per 60, карта бросков |
| `/v1/edge/goalie-5v5-top-10/{sort}/...` | Топ-10 вратарей 5v5 |
| `/v1/edge/goalie-5v5-detail/{playerId}/...` | Детали SV% 5v5 |
| `/v1/edge/goalie-shot-location-top-10/...` | Топ-10 по зонам бросков |
| `/v1/edge/goalie-shot-location-detail/{playerId}/...` | Карта бросков вратаря |
| `/v1/edge/goalie-save-percentage-detail/{playerId}/...` | SV% за последние 10 игр, games above .900 |
| `/v1/edge/goalie-comparison/{playerId}/...` | Сравнение со средним по лиге |

**Ценность:** Высокая. GSAE (goals saved above expected) — главная метрика для оценки вратарей.

## 4. Web API: дополнительные эндпоинты

Базовый URL: `https://api-web.nhle.com/v1/`

### 4.1 Профиль игрока

**Эндпоинт:** `/v1/player/{playerId}/landing`

**Что содержит:** полный профиль — ФИО, фото, рост, вес, draft info, текущая команда, карьерная статистика по сезонам, награды, рекорды.

**Ценность:** Высокая. Позволяет показать карточку игрока с карьерной историей и наградами. Сейчас в БД только минимальные данные.

### 4.2 Игровой лог игрока

**Эндпоинт:** `/v1/player/{playerId}/game-log/{season}/{gameType}`

**Что содержит:** построчная статистика каждого матча за сезон (дата, соперник, голы, ассисты, +/-, TOI, броски и т.д.).

**Ценность:** Высокая. Позволяет строить графики формы игрока, серии, тренды. Данные частично есть в `game_player_stats`, но game-log удобнее и включает доп. информацию.

### 4.3 Расписание и результаты

| Эндпоинт | Описание |
|----------|----------|
| `/v1/schedule/now` | Расписание сегодня (все матчи) |
| `/v1/schedule/{date}` | Расписание на конкретную дату |
| `/v1/score/now` | Результаты матчей сегодня |
| `/v1/score/{date}` | Результаты на дату |
| `/v1/club-schedule-season/{team}/now` | Расписание команды на весь сезон |

**Ценность:** Высокая. Позволяет реализовать:
- Уведомления о предстоящих матчах
- "Какие матчи сегодня?" без привязки к загруженным данным
- Расписание конкретной команды на ближайшую неделю

### 4.4 Game Landing и Game Story

| Эндпоинт | Описание |
|----------|----------|
| `/v1/gamecenter/{gameId}/landing` | Расширенная информация о матче: 3 звезды, серии команд, лидеры матча |
| `/v1/wsc/game-story/{gameId}` | Нарративная сводка матча |
| `/v1/gamecenter/{gameId}/right-rail` | Боковая панель: серии, ключевые моменты |

**Ценность:** Высокая. `/landing` содержит "три звезды матча" — востребованная информация, которой сейчас нет.

### 4.5 Плейофф

| Эндпоинт | Описание |
|----------|----------|
| `/v1/playoff-series/carousel/{season}` | Обзор всех серий плейофф |
| `/v1/schedule/playoff-series/{season}/{letter}` | Расписание конкретной серии |
| `/v1/playoff-bracket/{year}` | Сетка плейофф |

**Ценность:** Высокая (сезонно). Во время плейофф — самая востребованная информация.

### 4.6 Драфт

| Эндпоинт | Описание |
|----------|----------|
| `/v1/draft/rankings/now` | Текущие рейтинги проспектов |
| `/v1/draft/rankings/{year}/{category}` | По категориям (NA skaters, Int skaters, NA goalies, Int goalies) |
| `/v1/draft/picks/{year}/{round}` | Результаты драфта по раундам |
| `/v1/draft-tracker/picks/now` | Трекер текущего драфта |

**Ценность:** Средняя. Интересно в июне-июле, в остальное время — мало запросов.

### 4.7 Проспекты команд

**Эндпоинт:** `/v1/prospects/{team}`

**Что содержит:** список проспектов команды — молодые игроки в системе.

**Ценность:** Средняя. Дополняет информацию о команде.

### 4.8 Shift Charts (смены игроков)

**Эндпоинт:** `api.nhle.com/stats/rest/en/shiftcharts?cayenneExp=gameId={id}`

**Что содержит:** каждая смена каждого игрока в матче — время начала, конца, длительность, номер, период.

**Ценность:** Низкая для Telegram-бота (огромный объём данных), но высокая для продвинутой аналитики.

### 4.9 Лидеры и вехи

| Эндпоинт | Описание |
|----------|----------|
| `/v1/skater-stats-leaders/current` | Лидеры по голам, ассистам, очкам и т.д. |
| `api.nhle.com/stats/rest/en/leaders/skaters/{attr}` | Лидеры по конкретному показателю |
| `api.nhle.com/stats/rest/en/milestones/skaters` | Вехи (500-й гол, 1000-й матч и т.д.) |
| `api.nhle.com/stats/rest/en/milestones/goalies` | Вехи вратарей |

**Ценность:** Высокая. Milestones = "Овечкин забил 900-й гол" — отличный контент.

### 4.10 Реплеи голов

**Эндпоинт:** `/v1/ppt-replay/goal/{gameId}/{eventNumber}`

**Что содержит:** ссылка на видеореплей конкретного гола.

**Ценность:** Высокая для UX — видео прямо в Telegram.

## 5. Приоритизированные рекомендации

### Приоритет 1: Быстрые победы (малая доработка, высокая ценность)

Эти данные добываются тем же способом (тот же API, та же пагинация), просто другой `{report}` вместо `summary`.

#### 1a. Заполнить пробелы в существующих таблицах

**Что:** Использовать отчёт `timeonice` для полевых игроков, `savesByStrength` для вратарей.

**Зачем:** Сейчас 7 полей TOI в `players_season_stats` = `"00:00"`, а 6 полей PP/SH/EV splits вратарей = `0`. Данные уже есть в схеме, нужно только получить.

**Трудозатраты:** ~2 часа. Добавить 2 запроса к API в `load_season_modern.py`, обновить соответствующие строки.

**Пример запроса:**
```
GET /en/skater/timeonice?cayenneExp=seasonId=20252026%20and%20gameTypeId=2
GET /en/goalie/savesByStrength?cayenneExp=seasonId=20252026%20and%20gameTypeId=2
```

#### 1b. Расширить парсинг play-by-play

**Что:** В текущем парсинге play-by-play не извлекаются `empty_net`, `winner_goal`, `is_ppg`, `is_shg` для таблицы `all_goals`. Эти данные доступны в полях `situationCode` и `goalModifier` того же эндпоинта.

**Зачем:** Позволит показывать "голы в пустые ворота", "победные голы", "голы в большинстве".

**Трудозатраты:** ~1 час. Доработать парсинг в `build_game_rows()`.

### Приоритет 2: Новые данные с высокой ценностью

#### 2a. Продвинутая статистика: Corsi/Fenwick/PDO

**Что:** Отчёт `goalsForAgainst` (или `puckPossessions` / `percentages`) — Corsi%, Fenwick%, PDO.

**Новая таблица:** `players_advanced_stats`

| Колонка | Тип |
|---------|-----|
| player_id | int |
| sat_pct (Corsi%) | double |
| usat_pct (Fenwick%) | double |
| pdo | double |
| oz_start_pct | double |
| dz_start_pct | double |
| goals_for_pct_5v5 | double |

**Зачем:** Corsi и Fenwick — стандарт продвинутой аналитики НХЛ. Многие фанаты знают эти метрики и хотят видеть их в боте.

**Трудозатраты:** ~4 часа. Новая таблица + запрос + новый хендлер бота.

**Пример запроса:**
```
GET /en/skater/goalsForAgainst?cayenneExp=seasonId=20252026%20and%20gameTypeId=2
```

#### 2b. Тип броска

**Что:** Отчёт `shottype` — голы и броски по типам (wrist, slap, snap, backhand, tip-in, deflection, wrap-around).

**Новая таблица:** `players_shot_types`

**Зачем:** "Овечкин забил 30 голов с кистевого и 15 со щелчка" — уникальная информация.

**Трудозатраты:** ~3 часа.

#### 2c. Вратари: GSAE (advanced)

**Что:** Отчёт `goalie/advanced` — goals saved above expected.

**Зачем:** GSAE — главная метрика качества вратаря в современной аналитике. Показывает, сколько голов вратарь "спас" сверх ожидаемого.

**Трудозатраты:** ~3 часа. Расширить `goalies_season_stats` или создать `goalies_advanced_stats`.

#### 2d. Команды: leadingtrailing + scoretrailfirst

**Что:** Рекорд команды при ведении/проигрыше по периодам.

**Зачем:** "Команда X выиграла 25 из 30 матчей, в которых вела после 2-го периода" — показывает характер.

**Трудозатраты:** ~3 часа. Новая таблица `teams_situational_stats`.

#### 2e. Буллитная статистика

**Что:** `skater/shootout` + `goalie/shootout` + `team/shootout`.

**Зачем:** "Кучеров — лучший буллитчик лиги (80%)" — всегда вызывает интерес.

**Трудозатраты:** ~3 часа. Новая таблица или расширение существующих.

### Приоритет 3: NHL EDGE (новый источник данных)

#### 3a. Скорость катания + скорость броска (топ-10)

**Что:** `/v1/edge/skater-speed-top-10/all/max/{season}/2` и `/v1/edge/skater-shot-speed-top-10/all/max/{season}/2`

**Зачем:** "Самый быстрый игрок НХЛ" и "Самый мощный бросок" — вирусный контент.

**Трудозатраты:** ~4 часа. Новая таблица `edge_skating_speed` / `edge_shot_speed`. Новый эндпоинт, но response простой (top-10 списки).

#### 3b. Зональное время команд

**Что:** `/v1/edge/team-zone-time-details/{teamId}/now`

**Зачем:** Показывает стиль игры — атакующая команда (много OZ time) vs оборонительная.

**Трудозатраты:** ~3 часа.

#### 3c. Вратари EDGE: карта бросков

**Что:** `/v1/edge/goalie-shot-location-detail/{playerId}/now`

**Зачем:** Где вратарь пропускает — high-danger vs mid-range vs long-range. Для текстового бота можно показать как таблицу.

**Трудозатраты:** ~3 часа.

### Приоритет 4: Web API — расширение функционала бота

#### 4a. Расписание и результаты (real-time)

**Что:** `/v1/schedule/now`, `/v1/score/now`

**Зачем:** Команда бота `/today` — показать матчи сегодня. Не требует БД, можно вызывать API напрямую.

**Трудозатраты:** ~4 часа. Новый хендлер, без новой таблицы.

#### 4b. Три звезды матча

**Что:** `/v1/gamecenter/{gameId}/landing` → поле `threeStars`

**Зачем:** "Три звезды матча: 1. McDavid (2G, 1A)..." — классический формат.

**Трудозатраты:** ~2 часа. Добавить поле в `games` или парсить на лету.

#### 4c. Плейофф: сетка и серии

**Что:** `/v1/playoff-bracket/{year}`, `/v1/playoff-series/carousel/{season}`

**Зачем:** Во время плейофф — критически востребовано.

**Трудозатраты:** ~6 часов. Новые таблицы + хендлеры. Можно делать без БД (запрос к API на лету).

#### 4d. Вехи (milestones)

**Что:** `api.nhle.com/stats/rest/en/milestones/skaters`

**Зачем:** "Близок к 500-му голу", "1000-й матч" — значимые события.

**Трудозатраты:** ~3 часа.
