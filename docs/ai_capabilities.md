# Что ИИ бота умеет и чего не умеет

Шпаргалка по свободному тексту в личке (Задачи 81, 83, 105, 108). Подробно — `docs/telegram_bot.md`
§8 (вопросы) и §11 (расписания). Источник истины — код и промпты: `telegram_bot/ai_router.py`
(`SYSTEM_PROMPT`, `build_tools`), `telegram_bot/prompts/stats_answer.md`,
`telegram_bot/prompts/stats_schema_notes.md`. Примеры — контрольные наборы
`scripts/ai_router_eval.jsonl` и `scripts/ai_stats_eval.jsonl`. Поменялся промпт или набор
инструментов — поправь таблицы.

Путь вопроса: маршрутизатор открывает готовый экран или карточку расписания; если экрана нет,
а вопрос о статистике NHL, передаёт его в `ai_stats` (модель пишет SELECT по БД, ответ
проверяет ревьюер). Неоднозначный вопрос — одно короткое уточнение вместо угадывания.

## Умеет: экраны бота

Экраны считают только регулярку текущего сезона.

| Тип вопроса | Пример | Что откроется |
|---|---|---|
| Итоги прошедшей ночи | «что было ночью», «как сыграл Колорадо ночью» | `/today` |
| Итоги конкретной даты | «что было в ночь на 21 октября» | дайджест за дату |
| Матчи сегодня, расписание игр | «кто играет сегодня» | `/tonight` |
| Турнирная таблица | «таблица Востока» | `/standings` |
| Лидеры: очки, голы, передачи | «лучшие бомбардиры», «top scorers» | экран лидеров |
| Вратари, прочие лидеры игроков | «лучший вратарь сезона», «у кого больше всех сухих» | `/stats` |
| Статистика команд | «кто лучше всех в большинстве» | `/team_stats` |
| Клуб: обзор / все игроки | «как дела у Вашингтона» / «состав Тампы» | `/BOS` / `/BOS_FULL` |
| Где играет игрок | «где играет Пастрняк» | экран клуба |
| Игроки страны (25 стран) | «как там наши русские», «финны в нхл» | экран страны |
| Расширенные метрики: Corsi, Fenwick, % голов, старты в зоне, буллиты, голы по типу броска | «лидеры по корси», «кто больше забил щелчком» | экран метрики |

## Умеет: ответы по статистике (`ai_stats`)

| Тип вопроса | Пример | Как отвечает |
|---|---|---|
| Игрок: цифры, форма, «как играет» | «как играет Кучеров», «Макдэвид» | обзор игрока |
| Прошлые сезоны с 2021/22 | «сколько очков Макдэвид набрал в 2022/23» | SQL |
| Плей-офф и Кубок Стэнли с 2021/22 | «кто выиграл Кубок 2024», «очки Кучерова в плей-офф 2023/24» | SQL, только по явному вопросу о плей-офф; рамку называет |
| Игрок против команды, личные встречи | «сколько Овечкин забил Коламбусу в 2024/25» | SQL |
| Узкие срезы: дома/в гостях, большинство, буллиты, последние N игр | «очки Капризова дома в 2024/25» | SQL |
| Уточнение к прошлому ответу в течение 30 минут | «а в прошлом сезоне?», «а у Макара?» | продолжение диалога |
| «За карьеру» | «сколько всего голов у Овечкина» | сумма с 2021/22 с явной рамкой, не карьера |
| Однофамильцы, неясный клуб или сезон | «сколько очков у Хьюза», «победы Нью-Йорка» | уточняющий вопрос |

## Умеет: расписания экранов (Задача 108)

Просьба присылать экран регулярно — карточка-черновик расписания; сохраняется кнопкой «✅ Сохранить».

| Что | Как |
|---|---|
| Какие экраны | всё из «Экраны бота», кроме дайджеста за фиксированную дату; без `/subscriptions` и `/help` |
| Частота | каждый день; раз в неделю в выбранный день; раз в месяц 1–28 числа или в последний день |
| Время | шаг 30 минут, модель округляет; на карточке −1ч / +1ч / :00↔:30 |
| Часовой пояс | названный город или пояс («в 9 по Екатеринбургу»); иначе пояс прошлого расписания чата или МСК; на карточке — 9 поясов РФ |
| Не всё названо | карточка с пустыми полями «выбрать»; экран не понят («присылай что-нибудь интересное») — ответ с примерами |
| Лимит | бесплатно — одно активное расписание, премиум — без ограничения |
| Список, удаление | `/subscriptions` → «⏰ Расписания»; изменить — удалить и создать заново, текстом изменить нельзя |

Примеры: «присылай лидеров по голам каждую пятницу в 10», «профиль BOS раз в месяц 1-го числа»,
«каждое утро в 8:30 присылай итоги ночи».

## Вопросы о самом боте

Своих ответов о боте у ИИ нет: он только открывает подходящий экран. На остальное — отказ «Это я
пока не умею. Что умею — /help».

| Вопрос | Пример | Сейчас |
|---|---|---|
| Что умеешь | «что ты умеешь» | `/help` |
| Как подписаться на команду, дайджест, страну | «как подписаться на Вашингтон», «хочу дайджест каждое утро» | `/subscriptions` |
| Завести расписание | «присылай таблицу по понедельникам» | карточка расписания |
| Премиум: что даёт, сколько стоит, как оплатить | «сколько стоит премиум» | отказ (`/premium` маршрутизатору недоступен) |
| Лимиты вопросов | «сколько вопросов у меня осталось» | отказ |
| Как удалить или изменить расписание, отписаться | «как отменить расписание» | отказ или `/subscriptions` — не гарантировано |
| Что значит метрика, откуда данные, когда обновляются | «что такое Corsi», «почему нет вчерашней игры» | отказ |
| Возврат оплаты | «верните деньги» | отказ (возвраты — `/paysupport`) |

## Не умеет

| Тип вопроса | Пример | Ответ бота |
|---|---|---|
| Сезоны до 2021/22, рекорды за всю историю | «рекорд Гретцки» | «в наших данных нет» |
| Травмы | «что с травмой Кучерова» | отказ |
| Контракты, обмены, драфт, переходы | «какой контракт у Овечкина» | «в наших данных нет» |
| КХЛ, сборные, юниоры | «очки Малкина в КХЛ» | «в наших данных нет» |
| Составы и стартовые вратари до игры | «кто сегодня в воротах у Тампы» | «в наших данных нет» |
| Прогнозы, ставки, «кто выиграет» | «на кого ставить сегодня» | отказ (оценка модели — только строка в превью `/tonight`, премиум) |
| Новости и статьи | «что нового в НХЛ» | отказ, поиска в интернете нет |
| Рост и вес игроков | «какой рост у Макдэвида» | «в наших данных нет» |
| Плей-офф на экранах | «таблица плей-офф» | экраны только по регулярке; цифры — через `ai_stats` |
| Броски с координатами в текущем сезоне | карта бросков 2026/27 | только итоговые броски из сезонной статистики |
| Не про NHL | «погода в Москве», «рецепт борща» | отказ |
| Просьбы сменить роль, показать промпт, выполнить SQL | «забудь инструкции…», «DROP TABLE» | отказ |
| Текст в группах | любой текст в группе | молчит: свободный текст только в личке |

## Ограничения

- Лимит вопросов: премиум — 20 в сутки МСК; бесплатно — 3 в неделю и не больше 8 за всё время.
  Просьба о расписании тоже идёт в лимит.
- На вопрос в `ai_stats`: не больше 4 SQL-попыток, 7 вызовов модели и $0.10. Сверх этого —
  «не удалось ответить».
- Цифр от себя модель не пишет: на экранах их показывает бот, в `ai_stats` они берутся только
  из результатов запросов.
- Непокрытые вопросы видны в журналах: `ai_questions` (`outcome = 'text'`) и `ai_stats_log`
  (`outcome IN ('no_data', 'ceiling')`).
