# Исследование: на какую глубину NHL API отдаёт какие данные

Дата: 2026-11-17. Снимок, а не источник истины: перед решением о загрузке — перепроверить.
Дополняет «Почему с 2009/10» в карточке Задачи 121
([`../plan/tasks/task_model/task_121_history_load.md`](../plan/tasks/task_model/task_121_history_load.md)).

## Вывод

API отвечает на все сезоны с 1917/18 без пропусков матчей, но набор данных сужается ступенями.
2009/10 — последний сезон с координатами бросков, то есть граница «полного набора» загрузчика.
Голы, их авторы и передачи заполнены на всей глубине.

Внутри уже собранной истории есть разрыв: до 2019/20 в play-by-play нет `homeTeamDefendingSide`,
а `modeling/xg_model.py` без него падает (см. «Что учесть»).

## Метрики по важности и первый сезон

Уровни важности — решение человека 2026-11-17 (классика / второй темп / третий сорт);
разнесение метрик, которых он не назвал, — предложение агента, помечено «(предл.)».

Первый сезон найден бинарным поиском по всем сезонам 1917/18–2025/26: метрика «есть», если
она непуста и ненулевая хотя бы у одного из 50 игроков с наибольшим числом игр (сезонный отчёт)
или хотя бы в одном из 3 матчей середины сезона (протокол). «За сезон» — отчёты `stats/rest`,
из них строятся сезонные таблицы; «По матчам» — `boxscore` и play-by-play, из них — матчевые.

## Как проверялось

- **2009/10–2026/27** — локальный сырой слой `all_data/raw`, регулярка: 150 матчей на сезон
  для заполненности полей, 300 — для сверки голов и передач.
- **До 2009/10** — живой API: 1917/18, 1926/27, 1933/34, 1942/43, 1955/56, 1959/60, 1967/68,
  1974/75, 1979/80, 1983/84, 1987/88, 1993/94, 1997/98–2003/04, 2005/06–2008/09.
  По 4–6 матчей на сезон (`play-by-play`, `boxscore`, `landing`), 12 сезонных отчётов
  загрузчика (первые 100 игроков по числу игр), состав MTL, таблица на 1 марта сезона.
- **Голы и передачи** — отдельно: по 10 матчей на сезон и полные отчёты `skater/summary`
  и `goalie/summary` против суммы счетов всех матчей сезона.

Ограничение: выборка матчей до 2009/10 маленькая. Ступени видны надёжно, точный сезон
перелома между проверенными сезонами — нет (например, между 1993/94 и 1997/98).

На всей глубине есть: счёт, голы с автором, временем и типом состава, удаления, очки игроков,
победы и поражения вратарей, составы (`/v1/roster/{tri}/{season}`), турнирная таблица на дату
с тогдашними дивизионами (`/v1/standings/{дата}`).

Буллитный отчёт `skater/shootout` заполнен с 2005/06 (раньше буллитов не было).

## Голы и передачи

**Голы — полные с 1917/18.** Сумма голов в сезонных отчётах совпадает с суммой счетов матчей
до гола во всех проверенных сезонах до 2003/04 (например, 1979/80 — 5902 из 5902). С 2005/06
отчёты меньше на число матчей с буллитами (2005/06 — на 145): победный буллит идёт в счёт,
но не игроку. В 1917/18 разница 2 гола на 36 матчей. У каждого гола в сводке есть автор;
null в `goals`, `assists`, `points` в отчётах нет ни в одном сезоне.

**Передачи — заполнены, но их начисляли иначе.** Передач на гол: 1917/18 — 0,44, 1926/27 — 0,47,
1933/34 — 1,10, 1942/43 — 1,53, с 1955/56 — 1,6–1,8, как сейчас. Это правила учёта того времени,
а не пропуск в данных; сравнивать передачи и очки эпох до 1940-х с нынешними напрямую нельзя.

Расхождения между источниками:

- **Вратари в `boxscore`.** В строках вратарей нет полей `goals` и `assists`. Передача вратаря
  есть в play-by-play и в сезонном отчёте, но не в протоколе матча: расходится ~5% матчей
  (на одну передачу). Так же с голами вратарей (2012020446, 2024020720).
- **2009/10, play-by-play.** В ~10% матчей у гола не хватает одной передачи относительно
  `boxscore` (36 из 2822 передач в выборке, 1,3%). С 2010/11 расхождений нет. `all_goals`
  берёт передачи из play-by-play, `game_player_stats` — из `boxscore`.

## Что учесть

1. **xG до 2019/20 не посчитается.** `modeling/xg_model.py:82` требует сторону `left`/`right`.
   Пока нижняя граница датасета — 2021/22, это не проявляется. При сдвиге границы нужна
   нормировка стороны другим способом, например по `zoneCode` (заполнен на 100% с 2009/10).
2. **Счётчики плывут и в современных сезонах.** С 2024/25 потерь вдвое больше (15 → 30 за матч),
   отборов меньше (15 → 9), бросков в створ меньше (55 → 50); с 2023/24 больше блоков
   (29 → 34). Это смена учёта: признаки на этих счётчиках между сезонами несравнимы
   без нормировки.
3. **Вторая ступень для ИИ-ответов — 1997/98.** Даёт карьерные итоги с временем на льду
   и бросками. Цена — рамка в промптах становится двухслойной: продвинутая статистика
   с 2009/10, хиты и блоки за сезон с 2005/06.
4. **Модели сезоны до 2009/10 дают только счёт и броски в створ.** Для Elo счёта достаточно,
   но до 2005/06 были ничьи и не было буллитов.
5. **Скорость.** API притормаживает: сезонные отчёты отвечают по 2–4 секунды, проба одного
   сезона (30–40 запросов) шла 3–5 минут.
